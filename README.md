## 🌟 核心功能一览

### 1. 📱 影院级「单手模式」—— 竖屏握持的神
- **全屏沉浸视野**：点击底部粉色胶囊浮钮，瞬间切换影院级沉浸播放。
- **自由平移 & Minimap 鹰眼缩略图**：画面智能放大居中，拇指轻轻滑动即可在视频画面中上下左右自由平移，配合底部小白条手柄与触觉反馈，想看哪里就看哪里。
- **极速手势交互**：
  - **长按加速**：长按画面任意位置直接触发 2x / 3x 倍速快进；
  - **双击即播即停**：轻点两次快速启停；
  - **下滑顺畅退出**：单手轻轻下滑直接退出播放器，操作行云流水。

### 2. 💬 跨站神评聚合 & 智能高潮时间戳 —— 告别盲目快进
- **多源热评实时抓取**：一网打尽 Jable、JavDB、JavLibrary 等全网老司机真实热评。
- **AI 级智能降噪过滤**：内置几十道强力过滤规则，自动剔除同城骗子、广告推广、同学互圈、低质灌水，只留下高价值剧情解析与看点剧透。
- **高潮时间戳一键直达**：
  - 智能识别评论中的所有时间标记（如 `12:35`、`34分20秒`、`1:05:20`）；
  - 自动转化为**高亮跳转胶囊**，点击即可瞬间瞬移到对应画面；
  - 支持一键将老司机推荐的精彩区间转为 A-B 循环片段！

### 3. 🔁 A-B 片段循环 & 精彩多打点系统 —— 学习/复习神器
- **A-B 点无缝循环**：一键设置心动起止点，反复欣赏精彩画面不间断。
- **多彩标签药丸管理（Pill Tabs）**：支持对单部视频打多个标记点，支持自定义备注、颜色分类、起止时间微调。
- **抽屉式打点管理器（Marker Bottom Sheet）**：底部上滑随时唤出全部标记列表，点击即切。

### 4. ☁️ WebDAV 多设备智能云同步 —— 手机/电脑/平板无缝接力
- **全平台配置与打点同步**：支持坚果云、Alist、Nextcloud、Nginx 等任何标准 WebDAV 服务。
- **CRDT 分布式智能合并**：电脑端标记的精彩时间点，手机端 25 秒内自动无感拉取呈现；内置 30 天防复活墓碑机制，删除操作精准同步。
- **形态自适应隔离**：电脑端保持展开右侧神评栏，手机端保持纯净单手模式，多端设置互不干扰。

### 5. ⚡ 网站特权与极速纯净增强
- **强力去广告**：彻底干掉弹窗、劫持跳转与内嵌牛皮癣。
- **账号自动登录**：多域名凭据自动记忆，免去反复输密码。
- **自动极清画质**：加载即优选 1080P/4K 高码率画质。
- **详情与标题全展开**：视频简介、演员详情、长标题一目了然。
- **后台失焦自动暂停**：切后台或切换标签页时自动静音暂停（可在设置中随心开关）。

## 🛠️ 安装与使用指南

### 📱 苹果设备 (iOS / iPadOS)
1. **推荐方式 1**：在 App Store 安装 [Stay for Safari](https://apps.apple.com/cn/app/stay-for-safari-%E6%B5%8F%E8%A7%88%E5%99%A8%E4%BC%B4%E4%BE%A3/id1591620171)（免费版即可），打开脚本发布页点击安装。
2. **推荐方式 2**：在 App Store 安装 [Userscripts](https://apps.apple.com/cn/app/userscripts/id1463298887) 扩展配合使用。

### 🤖 安卓设备 (Android)
- 使用 **Via 浏览器**、**Kiwi 浏览器**、**Firefox** 或 **Edge**，安装 [Tampermonkey (油猴插件)](https://www.tampermonkey.net/) 后一键安装本脚本。

### 💻 电脑端 (Windows / macOS)
- Chrome / Edge / Firefox / Safari 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat (脚本猫)](https://scriptcat.org/) 即可畅享大屏体验。
