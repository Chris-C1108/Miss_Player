# 分流标签规范 (Triage Labels)

各项工程技能围绕 5 种标准分流角色开展工作。本文档将这些角色映射至本仓库任务追踪器中实际使用的标签字符串。

| mattpocock/skills 角色定义 | 本仓库实际使用标签 | 含义与说明                               |
| -------------------------- | ------------------ | ---------------------------------------- |
| `needs-triage`             | `needs-triage`     | 待评估：维护者需要评估此问题             |
| `needs-info`               | `needs-info`       | 待补充：等待提报者提供更多信息           |
| `ready-for-agent`          | `ready-for-agent`  | 准备就绪（Agent）：规格完整，可由 AI 执行|
| `ready-for-human`          | `ready-for-human`  | 准备就绪（人工）：需人工介入实现         |
| `wontfix`                  | `wontfix`          | 不予处理：暂不行动                       |

当技能提及某一角色（例如“应用 ready-for-agent 分流标签”）时，使用本表中对应的标签字符串。

后续如需调整标签词汇，可直接编辑此表右侧列。
