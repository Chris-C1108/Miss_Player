# Session Lessons & Anti-Patterns: UI/UX 深度重构、动静分离、色彩时序闭环与样式隔离治理

- Date & Time: 2026-10-29 12:08:23
- Focus Module: UIManager / LoopManager / CommentComposer / CSS Governance / Host Isolation

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **行内样式导致纯净观影高度锁死**：`div.tm-player-container.controls-hidden.tm-sidebar-hidden > div.tm-video-container` 在全屏纯净模式下被行内样式 `style="height: ...px; min-height: ...px;"` 卡死，无法填满屏幕，产生上下黑边与撕裂；
2. **Shadow DOM 外部裸节点样式完全丢失**：`DebugLogPanel` 直接被 `document.body.appendChild()` 挂载在宿主 `body` 顶层，而所有 CSS 被隔离在 `<miss-player-root>` 的 `ShadowRoot` 内部，导致调试面板退化为丑陋无样式的纯蓝方块；
3. **第三方油猴脚本 Z-Index 终极压制**：Peach JAV (`#peach-jav-action`) 等第三方脚本使用 `z-index: 2147483647` 脱水穿透挂在 `body` 上，由于处于同级兄弟节点，直接遮挡播放器控制界面；
4. **高光切片全员连锁变色 (Color Cascade Drift)**：由于胶囊色彩基于数组动态物理索引 `tabColors[index % length]` 实时计算，在时序中间插入新草稿时，新草稿预览色与保存色不一致，且保存后导致后续所有已有切片集体换色；
5. **草稿打点时序瞬移倒流**：草稿胶囊无论时间点多早均无脑 `appendChild` 到最末尾，保存后突然瞬移回最前，产生严重的视觉跳跃；
6. **横向滚动容器历史死留白吃掉 44px**：`tm-tab-scroll-container` 内部遗留了 `padding: 0 44px 0 0`，配合 8px gap 与 36px mask，导致左侧胶囊展示区域严重逼仄；
7. **二合一胶囊高度过扁与主次权重失衡**：28px 胶囊触控面积过小，且高频的 Quick Mark（快速打点）与低频的列表管理五五开平分，大拇指盲操易脱靶。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **DOM 工厂函数滥用行内样式**：`_uiFactories.js` 在创建元素时把数学计算值直接写死在 `el.style.height/minHeight` 上，状态切换（横屏或隐藏侧栏）时由于 CSS 特异度规则，行内样式压制类选择器（1,0,0,0 > 0,2,0），CSS 的 `height: 100%` 无法生效；
2. **组件挂载脱离了 Shadow DOM 边界**：编写新组件时随手挂到 `document.body`，误以为全局可见，却忽略了 Shadow DOM 的物理样式隔离屏障；
3. **盲目争夺 Z-Index 无效**：两个兄弟定位节点处于相同理论最大值 `2147483647` 时，层叠由插入顺序决定，后渲染的必盖在先渲染的上面；
4. **违背实体色彩持久性原则 (Color Permanence)**：把实体属性寄生在动态数组下标上，忽视了时序插入会重构全数组索引；
5. **时序与渲染流脱节**：时间胶囊基于时间轴排布，但渲染逻辑只遍历固定的 `this.tabs`，没有在构建 DOM 树时将草稿纳入时序二分插入。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **清空行内属性让 CSS 接管**：工厂函数生成纯净 DOM，在横屏与纯视频隐藏侧栏态，只要进入该状态机，强制清空 `container.style.height = ''; container.style.minHeight = '';`；
2. **智能探测挂载目标与自包含样式防护**：优先寻找 `playerContainer || shadowRoot` 挂载；并在组件内部自带内嵌 `<style>`，无论挂载在哪里样式 100% 具备；
3. **基于生命周期的宿主态声明式压制 (Host Lifecycle Suppression)**：在 `_host.css` 中利用 `body.tm-player-active` 声明 `display: none !important;`，观影时无感隔离第三方挂件，退出时原样恢复；
4. **实体色彩唯一权威 + 智能相邻避让算法**：
   - 确立 `tab.color` 为绝对持久属性，终生锁死；
   - 插入新草稿时，提取前驱与后继胶囊颜色建立黑名单，挑选全列表频次最少且不撞色的莫兰迪色，打点态与保存态 100% 同源；
5. **时序动态插入**：遍历 `this.tabs` 时对比 `draftStartTime < currentTabStartTime` 即时插入草稿胶囊，所见即所定，保存原地固化；
6. **几何与非对称主次分配重构**：
   - 彻底删除 `padding: 0 44px 0 0`，收窄 gap；
   - 右侧升级为 38px 高度、8px 圆角矩形；
   - 非对称分配：高频打点（`+`）占 60% 大靶心（宽约 39px），低频列表（`☰`）占 40% 紧凑入口。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN: 在 DOM 工厂函数或尺寸更新中给容器写入静态表现的行内像素 `el.style.height/minHeight` -> USE: 交由 CSS 规则（Grid 100% / Flex 100%）自适应管理，非拖拽态强制清理行内高度。
- FORBIDDEN: 将播放器子组件直接 `document.body.appendChild()` 变成裸节点 -> USE: 挂载到 `<miss-player-root>` 的 `shadowRoot` / `playerContainer` 内，并配备自包含样式兜底。
- FORBIDDEN: 试图通过将自身提升至 `z-index: 2147483647` 来压制第三方脚本 -> USE: 在 `_host.css` 中利用 `body.tm-player-active` 生命周期声明 `display: none !important;` 优雅隔离。
- FORBIDDEN: 基于切片数组动态下标 `tabColors[index % length]` 实时计算渲染胶囊颜色 -> USE: 确立实体 `tab.color` 权威，打点时通过相邻避让算法固化色彩，终生不漂移。
- FORBIDDEN: 无论打点时间戳为何均死板追加在序列末尾 -> USE: 根据 `startTime` 从小到大升序将草稿即时混排插入正确时序位置。
- FORBIDDEN: 在 Flex 横向滚动容器中保留历史遗留的死内边距（如 `padding-right: 44px`）替代布局间隙 -> USE: 结合 `flex: 1` 挤干死留白（`0 4px`），释放全部物理空间给正文内容。
- FORBIDDEN: 将高频核心操作与低频管理操作五五开均分空间 -> USE: 遵循菲茨定律采用非对称布局，高频操作赋予 60%+ 大靶心与清脆反馈。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- RULE: 遵循色彩持久性（Color Permanence）与时序真实模型：切片色彩必须固化在 `tab.color` 且打点与保存同源；草稿必须按时间戳即时混排于序列中，严禁基于数组下标动态算色导致全员漂移。(FORBIDDEN: `color = tabColors[index]` -> USE: `color = tab.color || allocateNeighborColor()`)
- RULE: 遵循 Shadow DOM 样式隔离边界：所有播放器组件必须挂载在 `shadowRoot` 内部；严禁向宿主 `document.body` 挂载缺少样式的裸节点。(FORBIDDEN: `document.body.appendChild(rawEl)` -> USE: `mountTarget = shadowRoot?.querySelector('.tm-player-container') || shadowRoot`)
- RULE: 遵循第三方高层叠挂件声明式隔离准则：针对宿主外部脚本的极限 Z-Index 抢占，严禁数值对抗，必须通过 `body.tm-player-active` 宿主轨生命周期声明隐形。(FORBIDDEN: `myZIndex = 2147483647` -> USE: `body.tm-player-active .third-party { display: none !important; }`)
