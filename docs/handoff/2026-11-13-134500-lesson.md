# Lessons Learned: 评论区增量懒加载展开保留、切源防空白与双轨对齐治理

- **日期**: 2026-11-13
- **版本**: v5.7.118-beta.027
- **分支**: `dev`

---

## 🛑 核心反模式与治理规范 (FORBIDDEN vs USE)

### 1. 结构重构后选择器脱节引发增量更新与状态全量退化 (Selector Desynchronization)
* **FORBIDDEN**:
  - 将核心渲染卡片由 `.jc-card` 重构为现代无框流式 `.jc-stream-row` 后，仅修改了模板字符串生成，未同步更新事件委托中的 `closest('.jc-card')` 与增量更新逻辑中的 `querySelectorAll('.jc-card[data-id]')`。
  - **惨痛代价**: 导致长评论点击展开时，`closest('.jc-card')` 返回 `null`，展开的评论 ID 从未被 `expandedCommentIds` 记录；同时 `patchSectionContent` 在比对现有卡片时因找不到旧选择器恒返回 0，误判增量失败，被迫退化为 `renderCommentsList()` 全量重绘 `innerHTML`，导致用户刚展开的长评论在懒加载时瞬间被折叠还原，严重破坏阅读体验。
* **USE**:
  - 重构核心 DOM 节点类名时，必须全局使用 `ffgrep` 检索所有涉及该类名的 `closest` 与 `querySelector`；
  - 采用复合容错选择器：`.jc-stream-row, .jc-card`；
  - 在单元测试中建立端到端断言（`tests/comments-patch-stream-scroll.test.mjs`），断言在新增数据增量追加时，已有卡片的 `data-collapsed` 状态与 DOM 实例绝对不变，且未触发父容器全量重绘。

---

### 2. 嵌套容器双重边距叠加导致对齐失准 (Nested Padding Accumulation)
* **FORBIDDEN**:
  - 在外层滚动容器 `.tm-comments-panel-list.tm-comments-list` 声明了 `padding: 8px 16px 0px 16px`，同时在内部流式行 `.jc-stream-row` 声明了 `padding: 13px 16px`。
  - **视觉破坏**: 外部与内部边距物理叠加为 32px，而顶部的水平分段栏 `.tm-comment-nav-bar` 仅有 16px 边距，导致评论内容区大幅向内缩进，文字参考线与顶部标签栏严重脱节错位，被用户一眼识别为视觉缺陷。
* **USE**:
  - 贯彻“**单一内边距归属原则**”：流式无框排布中，外层滚动容器的左右 padding 必须彻底归零（`padding: 0 0 24px 0` / PC 端 `padding: 8px 0px 0px 0px`）；
  - 仅由每一行 `.jc-stream-row` 独立负责自身的 `padding: 13px 16px`；
  - 与顶部 `.tm-comment-nav-bar` 的 16px 边线物理严格垂直共线，实现真正的 Apple 极简呼吸美学与严格微排版。

---

### 3. 多源分段器切源时假定数据已就绪，未做惰性自愈 (Lazy State Self-Healing)
* **FORBIDDEN**:
  - 在水平分段栏切源 `setActiveSource(siteKey)` 时，仅切换激活状态与样式显隐，未检查目标源当前的数据抓取状态；且未重置滚动条。
  - **严重故障**: 若用户首次切到从未加载过的源（状态为 `idle`），界面空空如也，由于没有主动拉取，用户误以为是 Bug；若旧源已向下滚动数百像素，切源后未复位 `scrollTop`，新源内容滚到了视口上方，呈现完全空白，必须上下滑动一下触发重绘才能看到内容。
* **USE**:
  - 在 `setActiveSource` 网关中建立**惰性自愈机制**：
    1. 切换目标源时，自动强制重置 `this.commentsList.scrollTop = 0`，确保内容永远顶格展示；
    2. 检查 `targetSite.status === 'idle'`，若未加载则立即自动调度 `this.loadSiteComments(siteKey, 1)` 补齐首屏拉取；
    3. `CommentCardRenderer.js` 针对初始状态提供 `.tm-comment-loader-graphic` 兜底动画，切源即刻展示柔和的三点跳跃加载，彻底杜绝白屏。
