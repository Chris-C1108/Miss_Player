3. **顶部标签栏严格依据设置菜单中的评论来源设置动态过滤**：
   - 在 `CommentPanel.js` 中新增 `getEnabledCommentSources()` 统一收敛；
   - `updateTabBar()` 动态渲染已开启的站点 Tab（如若关闭了 JAVLib，则顶部 Tab 栏完全不渲染 JAVLib）；
   - `updateCommentSources()` 与 `syncActiveSourceView()` 同步联动，若当前激活的源被用户关闭，自动平滑 fallback 至首个可用源。

4. **移动端 section 真跟手左右滑动切源 (Touch Drag & Snap with Live Follow-Finger Feedback)**：
   - 在 `CommentPanel.js` 接入完备的 `touchstart` / `touchmove` / `touchend` / `touchcancel` 状态机；
   - **轴向锁定检测**：前 8px 判定主轴方向，横向滑动大于纵向 1.2 倍时锁定横向切源手势并阻止页面滚动；
   - **GPU 实时跟手位移**：`translate3d(diffX, 0, 0)` 1:1 跟手移动，滑动中关闭 CSS transition 实现 0 延迟响应；
   - **边缘物理阻尼**：首源右拉或末源左拉施加 0.28 阻尼弹性反馈；
   - **释放阈值与弹性吸附**：位移超过 18% 视口或 60px 时执行 0.22s cubic-bezier 平滑切源动画；未达阈值或边界回弹执行 0.24s 弹性归位。

5. **每个评论条上方操作按钮（转为正序、转存、上报）统一重构，去除全部 emoji / 图标**：
