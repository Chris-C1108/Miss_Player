## 🎯 本阶段核心成果拓扑 (Accomplished Topology)

### 1. 二元主权数据模式 (Binary Data Sovereignty: 'shared' vs 'local')
- **去技术黑话与极客抽屉**：彻底淘汰分散的 Beta 抓取开关与复杂的 Supabase API 端点/Key 填报输入框，将其收敛为纯正 Apple 原生样式的双态分段选择器 (`SegmentedControl`)：
  - **`【 🌐 社区共享 】` (`shared`)**：呈现全网观众高能波峰与热评，用户自身足迹亦通过 120 槽位对数增量匿名回馈；
  - **`【 🔒 本地私有 】` (`local`)**：彻底切断公共网络通信，足迹与高光标记 100% 留存于本机与私有云盘。
- **物理级网络硬熔断**：在 `SupabaseService.js` 的所有对公读取（`fetchComments`, `fetchCrowdHeatmap`）与增量上报（`uploadComments`, `submitCommentReport`, `reportCrowdHeatmapDelta`）入口强制执行 `if (!this.isSharedMode() || !videoCode) return ...;`，本地私有模式下 0 字节上云，0 外部网络请求。

### 2. 公私双轨并存与 WebDAV 双写保障 (Dual-Write Pipeline)
- **私有云盘绝不闲置**：用户若在播放器中配置了 WebDAV（或局域网备用 WebDAV），无论当前处于「社区共享」还是「本地私有」模式，播放离散结算（暂停/结束/切后台/定时器）均**强制同步写入 WebDAV 独立文件 `/MissPlayer/heatmaps/[AVCODE].json`**，真正实现“写 2 份保证”；
- **四级读取优先级**：
  1. `IndexedDB` 本地极速瞬时渲染（0ms 零延迟）；
  2. `Cloudflare 边缘缓存 ➔ Supabase`（仅共享模式生效，拉取全网高能底轨）；
  3. `WebDAV 独立文件`（漫游合并本地缺失的跨设备私有足迹）；
  4. `源站 Provider 爬取`（仅当未收录时由本地视听解析兜底）。

### 3. 多语言与单元测试完备性
- 更新 `src/constants/i18n.js`，为中、英、繁、日、越 5 种语言完整录入 `dataMode`、`dataModeShared`、`dataModeLocal`、`dataModeSharedDesc` 与 `dataModeLocalDesc` 极简人本文案；
- 在 `tests/settings-order-and-sync.test.mjs` 中增加数据模式默认值与状态机校验；
- 在 `tests/heatmap.test.mjs` 中扩充测试 #10，严密断言本地模式下的 0 网络调用物理熔断与 WebDAV 正常上传双写保障；全项 CI 门禁（21 项人机工程、20 项 WebDAV 容灾切换、10 项热度图双轨测试）100% 通过。
