## 🚫 踩坑反模式与标准范式 (Anti-Patterns & Best Practices)

### 1. 为测试全网数据而清空本地数据库或删除云盘文件
* **反模式 (FORBIDDEN)**：
  - 为了排查社区高能进度条是否正常拉取，开发者或测试人员不得不清空浏览器 IndexedDB 或删除 WebDAV 上的 `/MissPlayer/heatmaps/[AVCODE].json`；
  - 这种侵入式测试会导致用户真实积累的播放足迹不可逆丢失，并且换设备时数据已被清空。
* **标准范式 (USE)**：
  - **表现层（View）独立隐匿，数据层（Model）忠实运转**：
    1. 在设置面板提供受控开关 `hidePrivateData`（不显示私有数据）；
    2. 开启时仅在 SVG 渲染层对顶轨 `pathElement` 设置 `display: none` 并跳过 `renderSvg()` 路径计算，使全网珊瑚金底轨 `pathCrowdElement` 纯粹独占展现；
    3. 后台数据管道（IndexedDB 离散写入、WebDAV 权威备份）正常运行，绝不中断；
    4. 关闭开关后通过 `setPrivateDataHidden(false)` 立即原样重绘，实现 0 丢失、0 破坏的无损可逆测试。

### 2. 多次重绘导致显示状态被意外覆盖重置
* **反模式 (FORBIDDEN)**：
  - 在 `renderSvg()` 等核心绘制函数中未检查全局显隐状态标志（`isPrivateDataHidden`），直接调用 `this.pathElement.setAttribute('d', pathD)` 或无条件重设 `display: block`；
  - 导致在播放过程中随 `timeupdate` 或暂停/播放事件触发重绘时，原本已隐藏的私有顶轨再次错误闪现。
* **标准范式 (USE)**：
  - **渲染网关第一行状态前置检查 (State-Gated Rendering)**：
    ```javascript
    renderSvg() {
        if (!this.isEnabled || !this.pathElement || !this.bins) return;
        if (this.isPrivateDataHidden) {
            this.pathElement.style.display = 'none';
            return;
        }
        this.pathElement.style.display = '';
        // 正常计算路径...
    }
    ```
  - 确保不论外部何时触发重绘，状态网关均能严格执行隐匿策略，消除界面偶发闪变。
