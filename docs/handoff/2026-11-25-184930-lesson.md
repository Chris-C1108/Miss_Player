# Session Lessons & Anti-Patterns: 实例重建丢失首次开播历史与 JS 字符串下标切分扩展区汉字错位陷阱 (v5.7.123)

- Date & Time: 2026-11-25 18:49:30
- Focus Module: `src/player/core/PlayerCore.js`, `src/player/CustomVideoPlayer.js`, `src/player/subtitles/SubtitleChineseConverter.js`, `src/player/subtitles/SubtitleManager.js`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
- **中途退出再进播放器反复跳回首个高光**：`FloatingButton.handleButtonClick()` 每次点击都会销毁态重建一个全新 `CustomVideoPlayer` 实例，`shouldFirstCapsulePlay` 无条件判断设置与高光数导致退出重入时再次强制跳到第 1 个高光，洗掉当前播放进度。
- **简繁映射表扩展区汉字 UTF-16 代理对偏移错位**：生成 `T2S_TO` 映射串中包含 CJK Extension B 字符（UTF-16 占 2 个 code unit），若按 `str[i]` 下标逐一对齐会造成错位后的所有汉字全部映射错误。
- **ASS/SRT 标签污染与通用 `zh` 误标风险**：对整份字幕文件直接跑全文本简繁转换可能破坏 ASS `{...}` 特效块或通用 `'zh'` 标签下原本就是繁体的字幕文本。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
- **会话生命周期与 DOM/控件持久化失配**：`CustomVideoPlayer` 与 `PlayerCore` 属于瞬态播放会期对象，退出即置空，只有宿主 `<video>` 与常驻 `FloatingButton` 跨越单页会话存在；未将「已进入过影院模式」绑定到视频标识与常驻载体上。
- **JS UTF-16 `.length` vs Unicode Codepoint 差异**：含增补平面（Surrogate Pair）的字符必须通过 `Array.from(str)` 与 `for..of` 码点遍历对齐。

## 3. PROVEN SOLUTION (验证有效的解决方案)
- 使用 `getTheaterSessionKey(video, avCode)` 组合 `video.dataset.mpTheaterEnteredKey` 与 `FloatingButton._enteredTheaterKeys` 形成双保险重入识别（SPA 换片仍重置，同片宿主重构 `<video>` 仍命中），重入时改走 `restoreVideoState` 续播并保护 `resumeProgressTime > 1`。
- 在 `SubtitleChineseConverter.js` 严格采用 `Array.from()` / `for..of` 构建与查表，分格式剔除 ASS `{...}` 与 SRT/VTT 标签及时间戳后转换对白文本，结合 `detectChineseScript()` 识别隐式繁体字幕。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN (禁止做法)：把仅应首次触发的状态放在随退出销毁的 `CustomVideoPlayer` 实例字段上；使用 `str[i]` / `str.length` 索引可能包含 CJK 扩展区汉字的并行映射字符串；对 `.ass`/`.srt` 原始全文直接做正则无差别替换而不隔离时间戳与 `{...}` 标签。
- USE (正规做法)：跨退出/重入的状态绑定到常驻 `FloatingButton` 与 `<video>` 节点并以当前视频会话 Key 作用域化；含增补平面字符映射一律使用 `Array.from()` 与 `for...of` 按码点遍历；字幕文本转换前按格式隔离时间轴、样式区块与控制标签。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- 提炼原子规则：`RULE: Bind cross-exit theater session flags to persistent video/FloatingButton carriers & iterate Unicode codepoints via Array.from/for-of when mapping CJK strings (FORBIDDEN: ephemeral CustomVideoPlayer flags or UTF-16 str[i] indexing across supplementary CJK planes -> USE: getTheaterSessionKey dual carrier + codepoint iteration & tag-aware subtitle conversion)`
