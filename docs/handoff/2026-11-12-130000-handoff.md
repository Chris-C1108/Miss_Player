## 🎯 本阶段核心成果拓扑 (Accomplished Topology)

### 1. 新增「不显示私有数据」测试与检视开关 (`hidePrivateData`)
- **场景与痛点闭环**：在双轨热度图架构下，顶轨（个人本机 IndexedDB + WebDAV 私有足迹）默认会以白光贝塞尔波形渲染在进度条上方。当开发者或用户想要检验 Cloudflare 边缘缓存与 Supabase 全网社区高能底轨（珊瑚金波形）是否正常同步时，私有足迹波形可能产生遮挡或干扰；
- **纯正 Apple HIG 布局**：在设置 ➔ **「Beta 实验室」** ➔ **「数据模式」** 分段选择器紧下方挂载 Apple 纯正 `ToggleRow` 开关：
  - **标题**：`不显示私有数据` (Hide Private Data)
  - **副标题**：`隐藏本机与云盘足迹，仅观察全网波形`
  - **默认值**：严格默认关闭 (`false`)，完全不影响正常观看足迹记录；
- **渲染层独立隐匿与数据安全隔离**：
  - 开启时：顶层私有波形 `pathElement.style.display = 'none'`，且 `renderSvg()` 不将私有贝塞尔路径刷上屏幕；底层全网社区高能波形 `pathCrowdElement` 独占清晰展示；
  - 数据安全：仅在表现层（UI View）进行隐匿，内存与后台 WebDAV 双写、本地 IndexedDB 依然忠实记录，用户测试完成后关掉开关，私有白光波形瞬间完整原样恢复，绝不丢失用户足迹！

### 2. 多语言与测试完备性
- 更新 `src/constants/i18n.js`，为中、英、繁、日、越 5 国语言录入 `hidePrivateData` 与 `hidePrivateDataDesc`；
