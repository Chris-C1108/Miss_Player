# Session Lessons & Anti-Patterns: WebDAV路径自愈、WebKit光标脱节、Safari横屏全屏与顶栏跑马灯Toast避坑总账

- Date & Time: 2026-11-10 19:47:09
- Focus Module: `WebDavClient` / `StrmIngestPipeline` / `UIManager` / `CommentComposer` / `videoSwipeManager` / `ui-feedback`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **WebDAV 目录不存在且无法自动创建**：
   - 现象：用户配置了正确的 WebDAV 端点与凭据，但虚拟入库时频繁报错“目录不存在且无法自动创建”；
   - 触发条件：用户配置的 WebDAV 基础路径已包含项目前缀（如 `/backup_configs/MissPlayer/`），流水线在拼接目标目录时重复附加了该前缀，生成了形如 `/backup_configs/MissPlayer/backup_configs/MissPlayer/peach-media/` 的畸形双重嵌套路径，导致服务器因父级不存在拒绝 MKCOL 创建。
2. **移动端发评栏展开时光标浮空漂移 (Caret Position Desync)**：
   - 现象：在 iOS Safari 下，输入框处于聚焦（键盘已弹起）时点击“+”号展开高光片段列表，蓝色的输入光标脱节悬浮在上方“附带高光片段”标题右侧，而实际输入框已在下方；
   - 触发条件：在固定底部定位的容器内部，子元素突发高度动画（`max-height 0.3s`），且在 0ms 同步调用了 `focus({ preventScroll: true })`；父容器带有 `will-change: transform` 创建了独立硬件合成层，WebKit 未能重绘合成层内的 Caret 图层。
3. **评论抽屉输入框点击误关高光抽屉**：
   - 现象：在评论底栏展开高光列表后，点击下方的输入框打字，高光列表意外被自动收起；
   - 触发条件：外部点击关闭判定逻辑仅检查了 `this.tagSelectModal.contains(e.target)`，输入框属于其兄弟元素，导致点击输入框被误判为“点击在抽屉外部”。
4. **控制面板进度条点击意外弹出虚拟键盘**：
   - 现象：用户在播放器控制栏点击或拖动进度条时，系统软键盘突然弹起；
   - 触发条件：收起状态的发评输入框仅应用了 `transform: translateY(100%)`，输入框未被 `disabled`，移动端触摸事件分发与预测命中穿透到了输入框；且进度条在 `touchstart` 里的 `e.preventDefault()` 阻止了默认失焦。
5. **iOS Safari 横屏视频区域上滑无法触发原生全屏**：
   - 现象：用户在横屏播放视频时向上滑动，Safari 的地址栏与底部工具栏始终不折叠，无法进入极简全屏模式；
   - 触发条件：`videoSwipeManager` 的 `_touchPreventDefault` 只要检测到垂直方向就无条件 `e.preventDefault()` 阻断了浏览器原生滚动，且宿主页面的 `html, body` 被固定死为 `overflow: hidden; position: fixed;`，导致 Safari 的内核收不到任何滚动量。
6. **Toast 样式违和与 Emoji 泛滥**：
   - 现象：暂停播放与状态提示时弹出大块刺眼的蓝色纯色背景与各色 Emoji，破坏了播放器的深空黑极夜毛玻璃视觉层次；固定 1 秒时长过于仓促。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **WebDAV 路径契约混乱**：上游业务逻辑错误将完整路径当成相对子路径传给客户端底层方法，底层又无防御性自愈逻辑，二者叠加产生致命路径倍增；
2. **iOS WebKit 硬件合成层脱节 (Layer Splitting)**：当祖先元素具有 `will-change: transform` 时，WebKit 会为该节点分配独立的硬件纹理图层，而输入框内部的 Caret Layer 在子元素高度动画过程中无法自动同步重排 bounding rect，导致光标停留在 0ms 时的绝对屏幕坐标；
3. **Shadow DOM 跨边界事件穿透与 Retargeting**：在宿主 `window` 上监听事件时，Shadow DOM 内部子节点冒泡上去时 `e.target` 会被浏览器重定向为 `<miss-player-root>`，仅靠 `contains(e.target)` 必定误判为外部点击；
4. **iOS WebKit 软键盘激活机制**：只要页面上存在可交互（非 disabled）的输入框，即使通过 CSS 移到视口外，若手势事件包含 `e.preventDefault()` 打断默认焦点链，软键盘就可能异常呼出；
5. **iOS Safari Minimal UI 触发逻辑**：Safari 隐藏顶部地址栏和底部工具栏的唯一判据，是检测到宿主页面发生了真正的纵向物理滚动位移（Page Scrolling），全屏锁死 `overflow: hidden` 会从物理上彻底扼杀全屏机制。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **WebDAV 防重叠自愈保护 (Deduplication Guard)**：
   - 在 `WebDavClient.uploadFile` 头部加入智能剥离前缀：
     ```javascript
     const normDirNoSlash = dirPath.replace(/^\/+|\/+$/g, '');
     if (normDirNoSlash && targetPath.startsWith(normDirNoSlash + '/')) {
         targetPath = targetPath.slice(normDirNoSlash.length + 1);
     }
     ```
   - 上游精准传递目录与文件名，MKCOL 失败且最终目录不存在时给出人本化提示。
2. **Caret 硬件层自立与多阶微帧校准 (`realignCaret`)**：
   - 移除父级 `will-change: transform`，给输入框显式设置 `transform: translateZ(0);` 自立合成层；
   - 展开抽屉时不在 0ms 强聚焦，在过渡动画阶段（rAF, 60ms, 180ms, 320ms）分阶段校准：
     ```javascript
     const pos = input.selectionStart ?? input.value.length;
     input.setSelectionRange(pos, pos);
     input.blur();
     input.focus({ preventScroll: true });
     ```
3. **收起态物理禁用锁 (`disabled`) 彻底封印软键盘**：
   - 发评栏 `closeComposer()` 时强制设置 `this.commentInput.disabled = true; this.commentInput.blur();`，`openComposer()` 时恢复；配合 CSS `visibility: hidden;`，浏览器底层绝对无法为 disabled 输入框唤起虚拟键盘；
   - `ProgressManager` 进度条操作首行主动触发 `activeElement.blur()`。
4. **横屏上滑穿透宿主驱动 Safari 原生全屏**：
   - `_touchPreventDefault` 判定横屏上滑（`isLandscape && this.dragDirection === 'vertical' && this.deltaY < 0`）时严禁阻止默认行为，并联动 `window.scrollBy`；
   - 在 `_host.css` 中为横屏媒体查询注入滚动余量：
     ```css
     @media screen and (orientation: landscape) {
       html.tm-player-active, body.tm-player-active {
         position: static;
         overflow-y: scroll;
         -webkit-overflow-scrolling: touch;
         min-height: calc(100vh + 80px);
       }
     }
     ```
5. **顶栏双槽广告翻滚跑马灯 Toast (Rolling Billboard Toast)**：
   - 将所有 Toast 统一汇入顶栏 `.tm-player-title` 区域，双槽平滑翻转，彻底消除独立悬浮大色块；
   - 全面过滤 emoji，采用 Apple 纯净微指示点（`.tm-toast-indicator-dot`）与纯白微排版；
   - 采用科学时长算法：`clamp(1800ms, 1400 + textLength * 110, 4200ms)`。
6. **WebDAV .strm 入库状态嗅探与右下角 ✅ 矢量角标**：
   - 外部站点统一通过 WebDAV 探测 `${targetDir}${avcode}.strm`，存在即点亮桃子按钮右下角的绿色圆形矢量白勾角标。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- `FORBIDDEN: 在 WebDAV 上传时将包含根路径的绝对路径直接追加到 config.path 之后 -> USE: 上游解耦传递基础目录与独立文件名，且客户端底层必须具备 Deduplication Guard 防路径重复叠合。`
- `FORBIDDEN: 在具有高度动画过渡的容器内部对 input 实施 0ms 同步重聚焦 -> USE: 移除父级 will-change，给 input 赋予独立合成层，并在动画关键帧分阶段微任务刷新 Caret 物理坐标。`
- `FORBIDDEN: 仅靠 transform: translateY(100%) 隐藏移动端带 input 的底栏 -> USE: 收起时必须物理声明 input.disabled = true; blur(); 配合 visibility: hidden; 彻底杜绝软键盘误激活。`
- `FORBIDDEN: 在横屏模式下为全屏播放器锁死 html, body 为 position: fixed; overflow: hidden; 并阻止上滑手势 -> USE: 横屏模式释放固定定位并注入微量滚动空间，上滑手势放行穿透并联动 window.scrollBy 以折叠 Safari 工具栏。`
- `FORBIDDEN: 向 document.body 挂载脱离 Shadow DOM 的裸 Toast 节点或使用高饱和度纯蓝底色块与 Emoji -> USE: 统一收敛为顶栏双槽广告翻滚跑马灯，采用深空黑毛玻璃底色、Apple 微指示圆点与科学阅读时长算法。`
- `FORBIDDEN: 在非自托管站点强依赖 Peach Dedicated Token 查询影片在库状态 -> USE: 统一通过 WebDAV 探测 .strm 文件是否存在，存在即点亮右下角 ✅ 矢量白勾角标。`

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- 提炼原子规则：`RULE: 移动端全屏交互与输入框治理 (FORBIDDEN: 浮层收起时保留活动 input、横屏模式锁死整页滚动阻止 Safari 工具栏折叠 -> USE: 抽屉收起时强制物理锁定 input.disabled = true、横屏上滑放行手势穿透驱动宿主窗口滚动以触发 Safari 原生全屏)。`
