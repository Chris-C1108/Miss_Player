- [x] **用户首选播放速度持久化与防宿主篡改**：
  - 彻底修复 `PlayerCore.restoreVideoState()` 中读取错误键 `getValue('playbackRate')` 导致每次进入播放器都重置为 1.0x 的历史缺陷，更正为 `preferredPlaybackRate`；
  - 在倍速切换事件中同步更新 `playerState.updateSetting('preferredPlaybackRate', nextSpeed)` 和 `videoState.playbackRate`；
  - 在 `PlayerCore` 中对 `loadedmetadata` 和 `canplay` 增加防重置保护：当宿主播放器脚本试图强制重置为 1.0x 时，自动恢复为用户的首选倍速。
- [x] **移动端视口收缩态手柄调整基准保持**：
  - 解决在移动端评论区视口自动回缩态（`is-collapsed-ratio`，约 210px）下，拖动视频下方手柄调整大小时，因为调用 `showControls()` 导致视频高度瞬间跳跃还原为历史展开高度（如 380px）并以此为基准调整的 Bug；
  - 捕获当前眼前所见物理高度 `currentVisibleHeight` 作为基准 `startHeight`，并同步更新 `customHeightPortrait`；
  - 在 `updatePortraitVideoHeight()` 中增加 `isDraggingHandle` 状态守卫，拖拽期间禁止任何自动高度覆盖。
- [x] **视频区域 Minimap 偶尔不显示的深度排查与修复**：
  - 彻底排查出手柄拖拽与 Minimap 状态割裂的 4 大核心根因：
    1. 尺寸未初始化：`_doUpdateConstraints` 在 `maxOffset <= 0` 时未初始化 Minimap 的宽高尺寸和视口滑块比例；
    2. 约束未刷新：按住手柄时依赖旧 `maxOffset`，紧凑初始态下判断为 0 导致未加 `.is-swiping`；
    3. 状态未联动：`DragManager` 垂直拖拽拉伸高度时未与 `videoSwipeManager` 产生状态联动；
    4. 计时器误杀：400ms 延迟移除定时器过早强行移除 `.is-swiping`（未判断 `DragManager.isDraggingHandle`）。
  - 落地闭环修复：
    1. 无论是否有水平溢出空间，前置固化计算 Minimap 的尺寸与比例，杜绝未定义空盒；
    2. 按下手柄时即时调用 `_doUpdateConstraints()` 刷新视口约束；
    3. `DragManager` 在拖拽开始、拖拽移动与拖拽结束全流程与 `SwipeManager` 深度联动并驱动视口刷新；
    4. `VideoSwipeManager` 400ms 定时器加入 `isDraggingHandle` 状态守卫。
- [x] **自动化门禁与版本合规推进**：
  - 新增专用单元测试文件 `tests/player-fixes-verification.test.mjs`（6 大断言组）；
