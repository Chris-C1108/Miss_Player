# 会话交接记录 (Handoff): 控制面板进度条消失根因修复与核心控制行自愈归真 (`v5.7.118-beta.054`)

- **交接时间戳**: `2026-11-17 01:07:00`
- **版本**: `v5.7.118-beta.054`（分支：`dev`）
- **关联任务**: 修复用户反馈“控制面板进度条不见了” BUG

---

## 1. 根因诊断与实证

在 `Settings v2`（`v5.7.118-beta.044`～`048`）精简设置菜单时，已将 `showProgressBar`（进度条）、`showSeekControlRow`（快速跳转行）、`showLoopControlRow`（高光片段行）、`showPlaybackControlRow`（播放控制行）的 UI 开关从设置面板中移除，但代码层遗漏了历史兼容清理：
1. 仅 `showSeekControlRow` 与 `showCommentsSection` 做了强制显示，而 `PlayerState.js`、`SettingsManager.js`、`UIManager.js` 仍从存储中读取历史持久化值 `showProgressBar` / `showLoopControlRow` / `showPlaybackControlRow`，并对 `.tm-progress-row`、`.tm-loop-control-row`、`.tm-playback-control-row` 执行 `classList.toggle('is-hidden', ...)`。
2. `SyncManager.js` 的 `gatherLocalData()`、`mergeData()` 与 `applyDataToLocal()` 仍继续读取与写回这些已废弃开关的 `false` 值。
3. **复现结果**：任何在旧版本曾关闭过 `showProgressBar`、或经由 WebDAV 同步拉取了包含 `showProgressBar: false` 旧备份的用户，升级后 `.tm-progress-row` 会被加上 `.is-hidden`（`display: none !important`），导致进度条彻底消失且在 Settings v2 中没有任何开关可以恢复。

---

## 2. 本次修复拓扑

| 模块路径 | 修复内容 |
| :--- | :--- |
| `src/player/state/PlayerState.js` | `loadSettings()` 中遍历 `permanentRowKeys = ['showProgressBar', 'showSeekControlRow', 'showLoopControlRow', 'showPlaybackControlRow']`，发现存储非 `true` 时自动 `setValue(rowKey, true)` 自愈并强制置 `true`；`saveSettings()` 固定写 `true`。 |
| `src/player/managers/SettingsManager.js` | 兜底 `loadSettings()` / `saveSettings()` 同步自愈并固定写 `true`；`updateControlRowsVisibility()` 对核心四行统一调用 `.classList.remove('is-hidden')`。 |
| `src/player/ui/UIManager.js` | `updateControlPanelVisibility()` 对 `.tm-progress-row`、`.tm-seek-control-row`、`.tm-loop-control-row`、`.tm-playback-control-row` 统一调用 `.classList.remove('is-hidden')`。 |
| `src/sync/SyncManager.js` | `gatherLocalData()` 固定输出 `true`；`mergeData()` 与 `applyDataToLocal()` 对上述 4 个核心行及 `showCommentsSection` 强制自愈为 `true`，阻断旧版云端备份覆盖。 |
| `tests/player-fixes-verification.test.mjs` | 新增「测试 27」：静态门禁校验四端自愈与防隐藏契约。 |
