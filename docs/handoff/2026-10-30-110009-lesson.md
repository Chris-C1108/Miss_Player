# Session Lessons & Anti-Patterns: 存储双写互愈、Shadow DOM 事件穿透、坐标特异度锁死与物理插槽架构

- Date & Time: 2026-10-30 11:00:09
- Focus Module: `storage.js`, `SyncManager.js`, `LoopManager.js`, `SettingsManager.js`, `_player.css`, `CommentPanel.js`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **配置莫名其妙丢失**：用户开启实验特性或填入 Supabase 端点 Token 后，换个域名、刷新或切后台唤醒后经常被静默重置为空或关闭。
2. **设置菜单位置倒错**：WebDAV 同步后，云端同步卡片瞬移到了第一分段（控制与手势）之后。
3. **设置菜单白屏闪烁**：WebDAV 每次点击同步后整张设置面板发生明显的 DOM 销毁重排白屏闪烁。
4. **控制面板呼出时从左下方斜飞**：控制面板从隐藏到显示时，所有元素以 45 度角从左下方向右上方弹射滑行。
5. **手机竖屏控制面板严重左偏 50%**：静音键被挤出屏幕左侧，右侧空出巨大半屏死黑，按钮换行挤压。
6. **胶囊长按编辑时间跳转被误取消**：长按编辑胶囊后调整时间，一旦时间跳出 `[startTime, endTime]` 区间，编辑态被强退。
7. **胶囊区域左右滑动手势失效**：胶囊槽无法横向滑动与滚动。
8. **外发光与呼吸灯被平平切断**：静音按键、切片胶囊、倍速按键四周出现平直生硬的黑色截断横线。
9. **评论列表增量加载导致已展开长文被折叠**：后台新评论到达或分页加载时，已展开的长文评论缩回折叠。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **单轨存储与时序抖动（Silent Downgrade Pitfall）**：`storage.js` 在 GM API 成立时未镜像备份 localStorage；沙箱未就绪时读取空值，随后 `saveSettings` 将空值回写覆盖了 GM 存储。
2. **云端旧备份冲垮本地已配置项**：WebDAV 多端合并时，云端带高时间戳的旧备份中 `betaMode: false` 或端点为空，直接覆盖了本地开启状态。
3. **同步与异步 DOM 追加时序倒错**：第 1 分段同步 append，第 2、3 分段异步 idle append，展开状态下的第 4 分段（云端同步）被同步 append 导致其物理顺位变成了第 2 位。
4. **全量摧毁重建的暴力重绘**：同步完成回调中调用了 `createSettingsPanel()` 抹除 innerHTML，引发了闪烁。
5. **显示态与隐藏态的 X 轴基准冲突**：居中隐藏态写了 `translateX(-50%)`，而移动端显示态写了 `transform: none`；过渡动画时 X 轴从 -50%（左）向 0（右）移动，Y 轴从下向上移动，叠加形成左下往右上的 45 度斜飞。
6. **高特异度规则击穿移动端居中**：`.tm-player-container:not(.controls-hidden) .tm-control-buttons` 的 `transform: translate3d(-50%, ...)` 穿透进竖屏，把已经 `margin: 0 auto` 居中的面板再次向左平移了 50% 宽度。
7. **Shadow DOM 事件重定向误退**：点击 Shadow DOM 内部进度条冒泡至 document 时 `e.target` 重定向为 `<miss-player-root>`，`e.target.closest` 返回 null，被误判为“点击了播放器外部”而退出编辑。
8. **滚动容器误设 `pointer-events: none`**：在有 `overflow-x: auto` 的容器上设置 `pointer-events: none` 会导致浏览器触控合成器彻底禁用该容器的横向滑动手势。
9. **W3C 规范的双轴滚动裁剪冲突与盒模型零净空**：一旦容器设置 `overflow-x: auto`，垂直方向会被浏览器强制裁剪，且 `mask-image` 会建立 Alpha 裁剪表面；当容器内部上下留白小于光晕半径时，光晕被容器边缘硬生生切平。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **GM API + localStorage 镜像双写与穿透互愈**：写入时同时写入两套存储；读取时优先读 GM，为空则穿透读取 localStorage 并反向自愈回写 GM。
2. **凭据非空防抹杀与 `betaMode` 开启保护**：在 `mergeData` 和 `applyDataToLocal` 中，只要本地有有效配置或开启状态，绝不允许云端空值或未开启状态覆盖关停。
3. **5 大固定顺序物理插槽架构 (Order-Preserved Slots)**：预先在 DOM 中焊死 5 个 Slot 节点，调度器通过 `targetSlot` 定向挂载，彻底消灭顺位倒错。
4. **WebDAV 纯就地无感局部更新**：移除 `createSettingsPanel()`，仅就地刷新状态文字与时间戳，零重绘零闪烁。
5. **媒体查询物理隔离横竖屏动效**：将居中悬浮模式的 `translate3d(-50%, ...)` 严格隔离在大屏/横屏媒体查询内；移动端竖屏锁定 `transform: none !important;`，动画 100% 委托外层底板纯垂直 Y 轴直起直落。
6. **接入 `e.composedPath()` 真实链路穿透检测**：准确探测点击是否落在播放器内部，杜绝 Shadow DOM 重定向误退，并在跳转逻辑中增加编辑态免疫守卫。
7. **解除滚动槽 `pointer-events: none`，移除负 Margin**：恢复 `pointer-events: auto` 与 `touch-action: pan-x`，并加入 touch 与鼠标拖拽平滑滚动增强引擎。
8. **移除 `mask-image`，扩充垂直安全净空**：移除粗暴遮罩，预留充裕 padding，呼吸灯收敛为聚焦光环 + 柔和紧凑外光晕，发光完全在安全区内自然融入背景。
9. **评论列表增量追加与 `expandedCommentIds` 保持**：重绘前自动扫描并持久化展开状态，新增卡片采用 DocumentFragment 增量追加。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN: 在油猴脚本中仅将关键配置单轨写入 GM 存储或 localStorage -> USE: 实施 GM API + localStorage 镜像双写与双读穿透互愈双轨备份机制。
- FORBIDDEN: 在多端同步逻辑中无脑用云端数据覆盖本地私有凭据或关键开启开关 -> USE: 注入非空防抹杀保护与开启意图防御性守护。
- FORBIDDEN: 混合使用同步 DOM 追加与异步调度追加 -> USE: 预先建立顺序绝对固定的 Slot 插槽结构，异步装配通过 targetSlot 定向装填。
- FORBIDDEN: 在子组件数据刷新时粗暴调用整个面板的重绘函数 -> USE: 实施纯就地局部 DOM 属性更新，杜绝白屏重绘闪烁。
- FORBIDDEN: 在全局通用类名上声明 `transform: translateX(-50%)` 并穿透到移动端竖屏 -> USE: 将带有横向偏移的居中规则严格收拢在横屏/大屏媒体查询内，竖屏使用 `margin: 0 auto` 居中且锁定 `transform: none`。
- FORBIDDEN: 在 document 上监听点击事件时使用 `e.target.closest()` 检测 Shadow DOM 内部元素 -> USE: 必须使用 `e.composedPath()` 遍历真实事件路径。
- FORBIDDEN: 为了微调外边距而在滚动容器上声明 `pointer-events: none` -> USE: 滚动容器必须保持 `pointer-events: auto` 与 `touch-action: pan-x`，使用标准 Flex 边距排版。
- FORBIDDEN: 在有 `overflow-x: auto` 的横向滚动容器上使用超大 `box-shadow`（>20px）或添加 `mask-image` -> USE: 移除 mask-image，预留足够垂直安全内边距，并将外发光设计为高聚焦轮廓环 + 紧凑微光晕。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- RULE: 核心配置多级存储双写互愈与云端非空防抹杀 (FORBIDDEN: 单轨存储与空值覆盖本地 -> USE: GM+localStorage双写穿透与防抹杀守卫)
- RULE: 动效坐标单一轴向约束与媒体查询绝对隔离 (FORBIDDEN: X/Y复合斜向飞入与横竖屏transform冲突 -> USE: 纯垂直单轴运动与竖屏transform:none锁定)
- RULE: Shadow DOM 跨边界事件穿透检测规范 (FORBIDDEN: document层直接使用e.target.closest -> USE: 必须遍历e.composedPath())
- RULE: 异步微前端容器固定插槽保序架构 (FORBIDDEN: 混用同步/异步appendChild导致顺位漂移 -> USE: Order-Preserved Slots)
