# Session Lessons & Anti-Patterns: 开播首次定位起播归零、Stay App 沙箱 fetch 上下文崩溃与会话永久拦截死锁 (v5.7.122)

- Date & Time: 2026-11-24 20:11:00
- Focus Module: `src/player/core/PlayerCore.js`, `src/userExperienceEnhancer/QualityManager.js`, `src/userExperienceEnhancer/UncensoredSwitcher.js`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
- **开播定位首个高光后播放不足 1 秒跳回 0:00**：进度条虽短暂跳转到首个高光，但起播后 1 秒内播放头被复位到 `0`；此外影院模式激活后后台画质切换若重载流同样会把当前进度洗回起点。
- **iOS Safari + Stay App 无码页探活失败且仅首次重开开关生效**：
  1. Stay App 沙箱直接解引用或调用 `unsafeWindow.fetch` 时未绑定接收者触发 `Illegal invocation` TypeError；`HEAD` 请求与带 `/dmXX/` 分片路径在镜像站或站点反代上容易被重定向回首页或拒答；
  2. 旧版把 `mp_uncensored_checked_<CODE> = 'redirected'` 永久写入 `sessionStorage`，导致同一标签页后续再次进入或二次测试直接短路跳过；
  3. 仅依赖整页跳转刷新在移动端交互割裂且容易丢状态，未优先提取 `.m3u8` 原地替换视频流；
  4. 新增单元测试时把被测试闭包引用的 `const emptyDoc` 声明在调用点之后，触发 ESM TDZ `ReferenceError`。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
- **媒体生命周期与异步起播重置**：浏览器 / HLS.js / iOS WebKit 在 `readyState === 1` 写入 `currentTime` 后，随后的 `play()`、`loadeddata`、`canplay`、`playing` 阶段仍可能把播放头复位回 `0`；单次 `video.currentTime = target` 无法对抗多阶段复位。
- **油猴管理器原生方法绑定与永久状态缓存反模式**：Stay App 沙箱下分离调用 `unsafeWindow.fetch` 丢失 `this` 上下文；`sessionStorage` 字符串永久哨兵在单页反复测试与动态渲染下缺乏自然过期或节点级边界，造成“只在开关重置时工作一次”的假死现象。

## 3. PROVEN SOLUTION (验证有效的解决方案)
- 在 `PlayerCore` 建立有界、可自动撤防的 `armInitialHighlightSeek()` 守卫（覆盖 `loadedmetadata` 至稳定推进后自动撤防，用户手动 `seeking` 立即撤防）并协调 `QualityManager` 在影院模式活跃期间不重装流。
- 在 `UncensoredSwitcher` 采用 `fetch` -> `unsafeWindow.fetch.bind(unsafeWindow)` -> `GM_xmlhttpRequest` 三级 `GET` 探活通道，并复用 P.A.C.K.E.R. 解包提取 `.m3u8` 地址执行 `replaceVideoStreamInPlace()`（Safari 原生 HLS 改写 `video.src` + `load()`；Hls.js 调用 `hls.loadSource()`），仅在节点级标记 `video.dataset.mpUncensoredApplied` 并用 10s 短期时间戳防整页回跳死循环。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN (禁止做法)：在 Stay App / 油猴沙箱直接传递未绑定 `this` 的 `unsafeWindow.fetch`；在 `sessionStorage` 写入无过期的永久拦截标志导致重复测试失灵；对起播定位仅做一次 `video.currentTime = t` 而不防护 `loadeddata/canplay/playing` 阶段回弹；在测试脚本中先引用后声明 `const` 导致 TDZ 崩溃。
- USE (正规做法)：调用宿主原生方法时显式 `.bind(unsafeWindow)` 并保留 `GM_xmlhttpRequest` 兜底；无码换流以节点级 `dataset` + 10 秒防死循环窗替代永久会话拦截，并优先提取 `.m3u8` 原地无刷换流；开播高光定位由 `armInitialHighlightSeek()` 守护至稳定推进后自动撤防。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- 提炼原子规则：`RULE: Preserve unsafeWindow receiver binding & short-lived per-node guards for userscript media hooks (FORBIDDEN: unbound unsafeWindow.fetch or permanent sessionStorage short-circuit locks -> USE: unsafeWindow.fetch.bind(unsafeWindow) + GM_xmlhttpRequest fallback + node dataset & bounded TTL guard)`
