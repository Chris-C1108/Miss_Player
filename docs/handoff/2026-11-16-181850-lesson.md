## 1. 移除布尔开关后必须同步在 State 加载期强制兜底默认值
* **现象**：移除「显示评论（`showCommentsSection`）」UI 开关后，若仍保留 `getBool('showCommentsSection', true)`，曾关闭过该项的历史用户本地缓存中仍残留 `false`，将导致评论区永久消失且无法在界面重新打开。
* **准则**：
  * **FORBIDDEN**: 仅删除 UI 开关却继续从持久化存储读取旧布尔状态 -> **USE**: 将已转正并下线开关的核心特性在 `PlayerState` / `SettingsManager` `loadSettings()` 阶段强制归一为固定默认值（`true`）。

## 2. 桌面侧边抽屉窄于移动端视口，双联内联控件须按窄容器实测行高
* **现象**：桌面端抽屉宽度为 `360px`（内宽 `312px`），反倒比移动全屏抽屉（`390px` / 内宽 `360px`）更窄；首次内联「快览与连播时长」时右侧双盒占 `195px`，导致桌面端 7 字中文标题折成两行（`h: 35`），而移动端仍为单行（`h: 18`）。
* **准则**：
  * **FORBIDDEN**: 只在移动端 `390px` 视口验证单行内联控件而不测量桌面窄抽屉 -> **USE**: 在最窄容器断点（`360px` 桌面抽屉）下实测 `titleEl.getBoundingClientRect().height` 并在 CSS 级压缩 padding/input 宽度与多语言短标题，保证全端严格单行。
