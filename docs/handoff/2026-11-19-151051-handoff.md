## 三、存储契约

| 层 | 位置 | 结构 |
| :--- | :--- | :--- |
| 本地 | IndexedDB `MissPlayerDB` → store `subtitles` | `{ key: AVCODE, items: [...], updatedAt }` |
| 远端 | WebDAV `/MissPlayer/media/[AVCODE]/_index.json` | 轻量索引（标题 / 语言 / 评分 / 收藏 / file 映射） |
| 远端正文 | `[AVCODE].[lang].[hash].[ext]` | 独立成文件，按 `id` 并集合并、`addedAt` 新者胜 |
| 配置同步 | `SyncManager.baseSettings` | 字幕偏好随主云同步双向漫游 |

> Peach STRM 已配置时优先复用其 `targetDir`，否则落 `media/[AVCODE]/`。

## 四、跳转反馈统一出口（本次三次演进，务必看 lesson）

`SeekFeedbackManager` 三轮修正的最终形态：

1. **绑定**：双通道 —— 直接绑 `playerCore.targetVideo`（Shadow DOM 内唯一可靠）+ `document` 捕获兜底（浅层视频）；`_attach()` 每 800ms 重试直到接管，视频更换自动解绑重绑。
2. **判定**：`位移 ≥ 1s` 播报；`700ms` 去重；开场 `2000ms` 还原期静默；`seeking` 事件密度 1.2s 内第 2 次起视为连续位移（拖动/循环装填）不再播报。
3. **不再读取任何外部模块的可变状态**（这是前两轮全静默的根因）。
