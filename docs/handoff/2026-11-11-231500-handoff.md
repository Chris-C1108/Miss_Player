# Handoff: WebDAV 双地址自适应 (LAN / WAN 自动故障转移) 与局域网回流自愈闭环

- **归档时间戳**：`2026-11-11-231500`
- **当前稳定版本**：`v5.7.118-beta.005`
- **当前 Git Commit**：`1dd3dc1`
- **分支状态**：`dev` (与 `origin/dev` 保持绝对同步)
- **关联需求与用户指令**：
  用户在家庭局域网与公网环境下使用自建 WebDAV 时，因家庭路由器缺少 NAT 回流 (Hairpin NAT)，导致局域网设备向公网域名 (`https://dav.loadingi.fnos.net:443`) 发起的 WebDAV 请求超时阻断，从而导致播放热度图及评论等无法成功跨域落盘。用户选择“方式一”，要求在 Miss Player 内部实现 WebDAV 双地址自适应 (LAN / WAN 自动故障转移)。

## 🎯 核心交付成果与拓扑变动

### 1. WebDAV 客户端双地址故障转移调度引擎 (`src/sync/WebDavClient.js`)
- **双地址候选提取 (`getCandidateUrls`)**：从连接配置中提取主地址 (`url`) 与局域网备用地址 (`lanUrl`)，去除空白字符并自动去重；
- **网络错误智能判定 (`_isNetworkError`)**：针对 `timeout`、`AbortError`、`Failed to fetch`、`NetworkError`、`ECONNREFUSED` 等物理网络故障进行精准判定；遇到 `401` / `403` 等显式鉴权失败时**禁止盲目切换试探**，直接快速失败；
- **自适应超时阶梯与快速截断**：
  - 当存在备用地址时，首选地址采用 **3.5 秒** 灵敏超时，快速截断无响应的网络连接，避免用户在页面等待 15 秒死挂起；
  - 最后一个候选地址采用 **15 秒** 完整宽限超时；
- **会话级活跃端点记忆 (`_activeUrlCache`)**：
  - 内存级 Map 映射，一旦某个端点成功握手，当前浏览器会话对该配置后续所有 WebDAV 读写操作直接 **0ms 优先使用该成功地址**，免去每一次请求重复超时切换的损耗；
- **全链路函数覆盖**：
  - `checkFileExists`、`ensureDirectory`、`testConnection`、`downloadBackup`、`uploadBackup`、`uploadFile` 等所有底层与业务 API 全量接入 `executeWithFailover` 调度。

### 2. Apple 风格极简设置卡片 (`src/player/managers/SettingsManager.js`)
- **局域网备用输入行 (`lanUrlRow`)**：
  - 紧贴在主服务器地址下方，去技术黑话，命名收敛为「**局域网备用**」；
  - 采用选填（Optional）设计，零心智负担；
  - **动态内网 IP 嗅探感知**：如果用户当前正处于内网 IP 站点（如当前页面 Host 为 `192.168.2.250`），Placeholder 自动预填提示 `例如 http://192.168.2.250:5005`；
- **动态保存与防丢失**：输入变动后立即通过 `SyncManager.saveWebDavConfig` 落盘，并在模态关闭或离散保存时由 `persistCurrentInputs` 兜底持久化。

### 3. 多语言支持与基础存储扩展 (`src/constants/i18n.js` & `src/sync/SyncManager.js`)
- 5 种语言完整支持（中简、中繁、英、日、越）：`webdavLanUrl` 与 `webdavLanUrlPlaceholder`；
- `SyncManager.getWebDavConfig()` 默认配置补齐 `lanUrl: ''`。
