# Session Lessons & Anti-Patterns: iOS WebKit 原生全屏劫持、HTML5 :modal inert 锁死与 Web Components 媒体容器抽离崩解避坑总账

- Date & Time: 2026-11-08 22:39:02
- Focus Module: `UIManager.js` / `FloatingButton.js` / `PlayerCore.js` / `videoSwipeManager.js` / `iosInline.js`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **自动跳入 iOS 系统全屏（AVPlayerViewController）**：用户在 iPhone Safari 点击浮动播放按钮的一瞬间，画面强制被系统全屏劫持。
2. **退出全屏后全黑且操作锁死**：退出系统全屏后，视频区域不显示任何画面，且页面上所有按钮、进度条、返回箭头均无法点击或滑动，必须强制刷新网页。
3. **退出播放器后浮动按钮彻底消失**：退出播放器后屏幕上没有任何唤起入口。
4. **下滑视频区域退出后宿主黑屏**：通过下滑手势关闭播放器后，原站视频区域变成黑屏，无法继续播放。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **WebKit 竞争冒险与遮挡检测**：
   - 旧代码在手势触发瞬间执行了 `preTargetVideo.play()`，紧接着下一帧播放器执行了跨 DOM 容器的节点迁移（`appendChild`）。对于正在起播的视频，跨容器移动会被 WebKit 底层中断并判定必须交由系统全屏承接。
   - 此外，当 `<video>` 被移入挂载在 `document.body` 的播放器时，若宿主上层存在 `<dialog open>`，WebKit 判定视频被顶层模态大面积遮挡，Occlusion Detection 也会强制弹出系统全屏。
2. **HTML5 `:modal` 与 `inert` 规范锁死**：
   - 现代站点（如 Peach Web）使用 `<dialog.showModal()>`。根据 WHATWG 标准，模态处于打开状态时，浏览器强制将 `document.body` 整体标记为 `inert`（禁用一切点击、触摸事件，事件直接穿透至 `<html>`）；
   - 旧播放器直挂 `document.body`，成为浏览器原生安全沙箱下的牺牲品，整屏点击失效。
3. **Web Components 掏空导致的流引擎损坏**：
   - 像 `<hlsjs-video>` 这样的自定义组件依赖 `<video slot="media">` 插槽。旧代码在第 278 行先行执行了 `this.targetVideo.parentNode.removeChild(this.targetVideo)`，直接把内核视频抽离成孤儿节点，导致 Hls.js 失去宿主崩解，抛出 `CHUNK_DEMUXER_ERROR_APPEND_FAILED` 致命错误，`readyState` 瞬间归 0 变成黑屏海报。
4. **退出生命周期遗漏与样式残留**：
   - `CustomVideoPlayer.prototype.close()` 未在退出时恢复 `callingButton.style.display = 'flex'`，导致浮钮永久隐藏。
   - 下滑手势使用了 `translateY(100vh)` 和 `opacity: 0` 做退出动画，但归还节点时未彻底重置 `transform` 与 `opacity`，导致视频被钉在视口下 100vh 之外无法看见。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **整装迁移 Web Components 媒体容器**：
   ```javascript
   // UIManager.js: 严格针对 mediaHostElement 整体迁移，严禁抽取内部 targetVideo！
   const nodeToMount = this.playerCore?.mediaHostElement || this.targetVideo;
   if (nodeToMount && nodeToMount.parentNode && nodeToMount.parentNode !== this.videoWrapper) {
       nodeToMount.parentNode.removeChild(nodeToMount);
   }
   this.videoWrapper.appendChild(nodeToMount);
   ```
2. **模态感知挂载，化解 `:modal` 阻断**：
   ```javascript
   // UIManager.js: 存在模态弹窗时挂载入 dialog 内部，继承最高渲染层级与交互权限
   const activeTopDialog = document.querySelector('dialog[open], [data-stage-host] dialog');
   const targetParent = (activeTopDialog && activeTopDialog.isConnected) ? activeTopDialog : document.body;
   targetParent.appendChild(this.rootHost);
   ```
3. **归还节点时全量清除内联拖拽样式**：
   ```javascript
   // PlayerCore.js: 彻底移除 transform, opacity, transition 等位移残留
   const clearMediaStyles = (el) => {
       if (!el || !el.style) return;
       ['width','height','max-width','max-height','margin','position','transform','opacity','visibility','transition','display','cursor','will-change','object-fit'].forEach(prop => el.style.removeProperty(prop));
   };
   clearMediaStyles(nodeToRestore);
   ```
4. **退出时同步唤醒浮钮**：
   ```javascript
   // CustomVideoPlayer.js: 显式恢复浮动唤醒按钮并自愈定位
   if (this.callingButton) {
       this.callingButton.classList.remove('is-hidden');
       this.callingButton.style.display = 'flex';
       if (this.callingButton._floatingButtonInstance) {
           this.callingButton._floatingButtonInstance.ensureTopLayerMount();
           this.callingButton._floatingButtonInstance.updateButtonPosition();
       }
   }
   ```

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN: 在通过 `requestAnimationFrame` 异步迁移 `<video>` 节点之前抢跑调用 `video.play()` -> USE: 严禁在迁移完成前触发播放，必须等 DOM 组装完毕且样式稳定后，通过静音互锁在播放器内部调用起播。
- FORBIDDEN: 强行将 `<video>` 单独从 `<hlsjs-video>`、`<dash-video>` 等 Web Components 自定义元素中 `removeChild` 抽离 -> USE: 智能探测上层媒体容器 `targetVideo.closest('hlsjs-video, dash-video, mux-video')`，整装迁移容器本身，保持内部 `slot="media"` 绑定与流引擎稳定。
- FORBIDDEN: 在页面存在打开的 HTML5 原生模态 `<dialog open>` 时将全屏遮罩挂载在 `document.body` 上 -> USE: 优先感知并将播放器宿主提升挂载至该 `<dialog>` 内部，直接获取 `:modal` 顶级层交互豁免，彻底杜绝浏览器对 `body` 的 `inert` 阻断锁死。
- FORBIDDEN: 在手势退出或播放器关闭时，只重置宽高而忽略 `transform` 和 `opacity` -> USE: 建立集中的 `clearMediaStyles()` 净化管道，彻底移除所有拖拽与动画遗留的内联属性，防止视频位移到视口外黑屏。
- FORBIDDEN: 在 `FloatingButton.js` 中将按钮隐藏后，在播放器关闭流程中遗忘将其显式恢复为 `display: 'flex'` -> USE: 在 `CustomVideoPlayer.prototype.close()` 的退出终点必须无条件恢复 `callingButton.style.display = 'flex'` 并调用自愈更新。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- 提炼原子规则：`RULE: Web Components 媒体容器整装迁移与 Top Layer 模态感知挂载准则 (FORBIDDEN: 从自定义媒体容器抽离裸 video 或在存在 :modal 弹窗时盲挂 document.body -> USE: 整装迁移容器本身并挂载入 activeDialog 内部以继承渲染与交互权限)`
