# Session Lessons & Anti-Patterns: 通用媒体盒模型缩放解耦、播放器退出单一出口漏斗闭环与 Web Components 挂载防护避坑总账

- Date & Time: 2026-11-09 00:59:17
- Focus Module: `_player.css` / `EventManager.js` / `CustomVideoPlayer.js` / `PlayerCore.js` / `FloatingButton.js` / `_host.css`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **全站竖屏拉伸放大与 Minimap 水平平移失效**：在 `52aa8d0` 中将 `.tm-video-wrapper video` 锁死为 `width: 100% !important; max-width: 100% !important; object-fit: contain !important;`，导致向下拖动调整手柄时视频不再按高度等比溢出，而 `VideoSwipeManager` 仍按高度计算虚拟溢出量，左右滑动时直接将视频滑出视口导致黑屏。
2. **退出路径双轨分裂导致浮钮永久消失**：下滑手势调用 `CustomVideoPlayer.close()`，而点击左上角返回按钮走 `EventManager.handleCloseButtonClick()`，后者不仅绕过了上层业务注销，而且漏传了 `rootHost` 参数，导致 `<miss-player-root>` 泄漏残留在 DOM 中，`FloatingButton.isPlayerActive()` 永久判定播放器处于激活状态，浮钮再也不显示。
3. **已下线死代码触发 TypeError 阻断退出**：Phase 19.9 删除了 `PeachWebBridge` 客户端瀑布寻源逻辑，但在 `CustomVideoPlayer.close()` 中遗留了 `PeachWebBridge.stopProgressTracking()` 调用，在 Peach Web 实例中下滑退出必抛 `TypeError` 中断所有后续清理逻辑。
4. **`cleanupExistingOverlays` 二次剥离 Web Components 媒体容器**：清理旧残留 root 时直接将 `innerVideo` 提取并 `document.body.appendChild`，导致 `<hlsjs-video>` 与内部 `<video slot="media">` 解绑，引发 MSE 管道损坏。
5. **模态弹窗内子节点 `display: none` 触发宿主 Resize 重置**：对 `dialog[open] > *:not(...)` 使用 `display: none` 会导致宿主弹窗内部元素物理宽高瞬降为 0×0，若宿主绑定了 ResizeObserver 或尺寸检测易引发状态紊乱。
6. **桌面端起播前 100ms 无谓吞音**：为了防 iOS Safari 全屏跳出而引入的临时静音策略未限制运行平台，导致在 PC / Mac 桌面浏览器上也总是先静音 100ms 再恢复。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **“特例污染通用”的盒模型反模式**：为适配个别站点的容器尺寸，直接抹除了通用播放器依赖多年的 `width: auto; max-width: none; height: 100%` 几何渲染契约，破坏了竖屏手柄与 Minimap 的底层物理数学假设。
2. **生命周期出口多头管理**：UI 事件处理器（点击关闭）与手势控制器（下滑关闭）各自持有局部销毁逻辑，缺乏单一收口漏斗，导致参数传递断层与 DOM 状态泄漏。
3. **架构重构后上游调用点未清理**：Phase 19.9 下线客户端寻源接力代码时，未完整检索全仓调用点，残留僵尸方法调用，缺乏静态检查与集成测试守卫。
4. **宿主隔离粒度过粗**：使用 `display: none` 会彻底破坏 DOM 的 Layout Box，而 `visibility: hidden` 既能完全隐藏画面并阻止一切事件响应，又能完好保留宿主 Layout Box。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **恢复通用媒体盒模型，容器透传居中**：
   ```css
   /* _player.css: 保持 height: 100% 驱动宽高比等比缩放溢出 */
   .tm-video-wrapper video,
   .tm-video-wrapper hlsjs-video,
   .tm-video-wrapper dash-video {
       width: auto !important; 
       height: 100% !important; 
       max-height: 100% !important; 
       max-width: none !important; 
       object-fit: contain !important; 
       transition: transform 0.2s cubic-bezier(0.4, 0, 0.2, 1);
       touch-action: pan-y;
       cursor: grab; 
   }
   .tm-video-wrapper hlsjs-video,
   .tm-video-wrapper dash-video {
       display: flex;
       justify-content: center;
       align-items: center;
   }
   ```
2. **生命周期退出单一出口漏斗 (Single Close Funnel)**：
   ```javascript
   // EventManager.js: 无论是点击按钮还是手势，一律收敛至 CustomVideoPlayer.close()
   handleCloseButtonClick() {
       try { if (window.self !== window.top) window.top.postMessage({ type: 'MP_IFRAME_COLLAPSE' }, '*'); } catch (_) {}
       if (typeof this.onClose === 'function') {
           this.onClose();
       } else {
           this.cleanup();
           this.playerCore.close(this.uiElements.overlay, this.uiElements.container, this.uiElements.playerContainer, this.uiElements.rootHost);
       }
   }
   ```
3. **Web Components 原子媒体单元整体抢救**：
   ```javascript
   // PlayerCore.js: 优先查找并抢救 closest('hlsjs-video, dash-video, ...')
   const mountHost = innerVideo.closest('hlsjs-video, dash-video, mux-video, [data-media-host]');
   const nodeToRescue = mountHost || innerVideo;
   if (nodeToRescue.parentNode) {
       document.body.appendChild(nodeToRescue);
   }
   ```
4. **Top Layer 无损隐藏与属性级热感应**：
   ```css
   /* _host.css: 隐藏画面并阻断事件，但保留 100% 原始布局尺寸 */
   body.tm-player-active dialog[open] > *:not(miss-player-root):not(.tm-floating-button) {
       visibility: hidden !important;
       pointer-events: none !important;
   }
   ```
   ```javascript
   // FloatingButton.js: 属性级感知与原生 dialog close 事件捕获
   this.mutationObserver.observe(document.body, { childList: true, subtree: true, attributes: true, attributeFilter: ['open', 'src'] });
   document.addEventListener('close', this._dialogCloseHandler, true);
   document.addEventListener('cancel', this._dialogCloseHandler, true);
   ```
5. **精准平台互锁收窄**：
   ```javascript
   // 仅在 iOS 触控设备上执行 100ms 临时静音以锁定 WebKit 行内图层
   const needTempMute = isIosDevice() && !originalMuted;
   ```

## 4. STRICT ANTI-PATTERNS (必须严格避免的反模式)
- `FORBIDDEN: 在 .tm-video-wrapper video 上设置 width: 100% !important 或 max-width: 100% !important` ➔ `USE: 保持 width: auto !important 与 max-width: none !important，通过 height: 100% 实现拉伸等比溢出与平移`。
- `FORBIDDEN: 在 EventManager 中私自调用 playerCore.close() 造成生命周期双轨分裂` ➔ `USE: 通过 onClose 回调将所有退出意图收敛至 CustomVideoPlayer.close() 统一销毁`。
- `FORBIDDEN: 下线模块或方法时仅删声明不删调用点` ➔ `USE: 全仓 ffgrep 搜索引用并在集成测试中加入静态防断言`。
- `FORBIDDEN: 抢救孤立视频节点时直接从 Web Components 容器中掏出裸 video` ➔ `USE: 检查 closest('hlsjs-video, dash-video, ...')，整体迁移宿主容器`。
- `FORBIDDEN: 对宿主模态弹窗内子节点使用 display: none 导致尺寸归零` ➔ `USE: 使用 visibility: hidden !important; pointer-events: none !important; 实现零重排无损隔离`。
- `FORBIDDEN: 将特定平台的防全屏临时静音策略无差别施加在所有桌面浏览器上` ➔ `USE: 通过 isIosDevice() 精准嗅探，桌面端即刻有声起播`。
