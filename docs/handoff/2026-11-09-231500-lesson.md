# Session Lessons & Anti-Patterns: 全局事件黑洞防穿透、iOS视口键盘抽屉适配、设置菜单ADHD标准化与Peach入库重构

- Focus Modules: `UISurfaceMachine.js` / `_player.css` / `CommentComposer.js` / `_comments.css` / `_settings_apple.css` / `PeachSection.js` / `PeachService.js` / `SettingsManager.js`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)

1. **SPA 页面切换与弹窗关闭导致浮钮永久丢失**：Peach Web 等单页应用在路由切换、媒体卡片切换或宿主原生 `<dialog>` 弹窗关闭时，由于无整页刷新，动态生成的浮动按钮经常被宿主 DOM 树更新冲刷或被错误判定为播放器已激活而隐藏。
2. **多输入框修改备注与转存时视口反复跳闪上移**：在打点备注或转存面板中，点击输入框调起移动端软键盘时，整个组件或外层视口从下往上弹出跳动，多个输入框切换焦点时反复剧烈抖动，底部露出大量空白。
3. **面板层叠时手势长按穿透至视频区域 (触发 Stay 下载)**：悬浮面板（如高光列表、设置菜单）置于视频区域上方时，用户在面板上的长按或轻微滑动操作穿透到底层 `<video>`，频繁触发 Stay App 自带的视频下载气泡或浏览器原生上下文菜单。
4. **菜单栏向上滑动导致底部出现大面积空白**：移动端竖屏操作菜单栏向上滑动时，拖拽手势冒泡穿透到播放器外层容器，整个播放器容器连同视口被一起向上推移，底部露出宿主大片空白背景。
5. **iOS Safari 虚拟键盘弹出未能顶起发评底栏**：点击发评输入框后，发评底栏被系统软键盘完全遮挡在下方，用户无法看到正在输入的内容。
6. **设置菜单认知过载与技术黑话冗余**：设置菜单中大量自解释选项带有繁复的说明副文本；存在早已过时或孤立的功能入口（如 JAVVerse 登录、流诊断探针 HUD、手动扫描按钮）；多处使用 `style.cssText` 违背动静分离原则。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)

1. **SPA 缺少长效生命周期感知闭环**：单次挂载策略无法对抗 SPA 的局部 DOM 频繁重建；仅监听 DOM 树变化不足以捕获 HTML5 原生 `<dialog>` 状态切换（原生弹窗的 `open` 属性变更并不产生 `childList` 变动）。
2. **输入框聚焦触发了宿主级窗口滚动 (Overscroll Leak)**：移动端浏览器在聚焦 `input` 时默认调用 `scrollIntoView`，若顶级容器没有锁定 `touch-action: none` 且没有限制窗口整体滚动，浏览器会自动将父级甚至 `window` 纵向上推；聚焦转移时重复触发尺寸计算引发二次抖动。
3. **缺乏顶层显式状态机与事件黑洞拦截层**：以往各个 UI 面板各自在局部做事件阻止，当面板层叠于视频上方时，底层视频仍保持 `pointer-events: auto`，未处理的长按（`contextmenu`）、滑动手势自然穿透到底层被宿主捕获。
4. **手势源头白名单隔离缺失与视口未加锁**：拖拽或滑动事件未在源头拦截，直接冒泡到外层 `.tm-player-container`；而外层容器缺少 `touch-action: none` 强约束，触发了 iOS WebKit 的全局橡皮筋（Rubber-band）滚动。
5. **虚拟键盘事件流中存在错误的互锁阻断**：在 `visualViewport` 的高度监听逻辑中，原先设置了 `isFocusLocked` 内部条件，导致在软键盘弹起的有效时刻（`keyboardHeight > 60`）设置物理 `bottom` 的代码被提前 return 阻断。
6. **职责边界混乱与反模式残留**：Phase 19 已将流寻源与防盗链代理收敛至服务端流网关，但前端仍残留 Phase 17 时代的 JAVVerse 登录跳转和客户端探针，增加了用户的认知负担。

## 3. PROVEN SOLUTIONS (验证有效的解决方案)

### 3.1 系统级全局事件黑洞与物理冻结 (Event Blackhole & Tree Freezing)
引入显式顶层状态机 `UISurfaceMachine` 与全局事件黑洞遮罩层 `.tm-surface-event-sink`：
```javascript
// UISurfaceMachine.js: 当任何浮层活动时，底层树物理冻结，多余操作吸入黑洞
activate(surfaceType, closeCallback) {
    this.activeSurface = surfaceType;
    this.closeCallback = closeCallback;
    this._attachEventBlackhole();
    // 底层视频与控制器彻底禁用指针事件，杜绝穿透
    if (this.videoContainer) this.videoContainer.style.pointerEvents = 'none';
}

_attachEventBlackhole() {
    // 拦截 touchstart, touchmove, touchend, contextmenu, mousedown 等所有手势并丢入黑洞
    const blackholeEvents = ['touchstart', 'touchmove', 'touchend', 'touchcancel', 'contextmenu', 'mousedown', 'click'];
    blackholeEvents.forEach(evtName => {
        this.eventSink.addEventListener(evtName, (e) => {
            // 放行活动面板内部元素与可编辑输入框
            if (this._isInsideActiveSurface(e)) return;
            e.stopPropagation();
            if (evtName !== 'touchstart') e.preventDefault();
        }, { capture: true, passive: false });
    });
}
```

### 3.2 播放器顶级容器 `touch-action: none` 与视口位移防失真
```css
/* _player.css: 播放器整体容器与视频区域绝对禁止整体纵向位移 */
.tm-player-container {
    position: fixed;
    top: 0; left: 0; right: 0; bottom: 0;
    width: 100%; height: 100%;
    overflow: hidden;
    touch-action: none; /* 彻底消灭上滑整体移位与底部留白 */
}

/* 内部垂直滚动容器限定在当前盒内滚动，禁止链式滚动 */
.tm-settings-panel,
.tm-comment-panel-inner,
.tm-comment-list-container {
    touch-action: pan-y;
    overscroll-behavior-y: contain;
    -webkit-overflow-scrolling: touch;
}
```

### 3.3 iOS `visualViewport` 物理 bottom 直接映射
在键盘高度大于 60 时，无视多余阻断，直接设置物理行内高度：
```javascript
// UIManager.js: 键盘弹出时无阻碍直接设置物理像素 bottom
if (keyboardHeight > 60) {
    commentSubmitBar.style.bottom = `${keyboardHeight}px`;
    sheetPanel.style.bottom = `${keyboardHeight}px`;
} else {
    commentSubmitBar.style.bottom = '0px';
    sheetPanel.style.bottom = '0px';
}
```

### 3.4 底部抽屉圆角与无模糊透明设计

### 3.5 设置菜单 ADHD 规范与动静分离
- **自解释项废除副文本**：如“显示进度条”、“按钮音效”、“默认静音”等彻底移除描述文本；
- **必要副文本收敛**：严格控制在 8–16 字以内，直指用户收益（如“A-B 区间循环”、“数据变动时后台静默同步”）；
- **彻底消灭 `style.cssText`**：SegmentedControl 与各卡片行全部使用预定义类（如 `.tm-about-channel-row`, `.tm-segmented-control`）；
- **连通性自动检测**：去除手动“测试”按钮，在输入变化或折叠展开时自动探测，顶栏状态灯即时同步；
- **服务地址支持删除**：提供 `.tm-peach-delete-btn` 一键清空已记录域名与 Token；
- **流网关规范提示**：注明必须是 Peach 服务端可访问地址，Token 需在部署环境变量中配置（默认 dev）。

## 4. STRICT ANTI-PATTERNS (必须严格避免的反模式)

- `FORBIDDEN: 在悬浮面板之下保持底层 <video> 的 pointer-events: auto` ➔ `USE: 面板激活时通过 UISurfaceMachine 将底层树置为 pointer-events: none，并挂载全局事件黑洞层彻底吞没手势`。
- `FORBIDDEN: 允许 .tm-player-container 默认滚动或继承父级 touch-action` ➔ `USE: 顶级固定容器锁死 touch-action: none; overflow: hidden;，可滚动子容器限定 touch-action: pan-y; overscroll-behavior: contain;`。
- `FORBIDDEN: 在 visualViewport 键盘避让逻辑中设置复杂的拦截守卫导致 bottom 设置失效` ➔ `USE: 只要 keyboardHeight > 60，无阻碍直接将物理像素映射到目标抽屉的 style.bottom`。
- `FORBIDDEN: 在设置菜单中为显然自解释的开关编写冗长副标题` ➔ `USE: 符合 Grice 准则，自解释项仅保留主标题，必要副文本严格压缩在 8~16 字直指收益`。
- `FORBIDDEN: 在 JS 组件中直接使用 style.cssText = '...' 书写静态表现样式` ➔ `USE: 声明标准 CSS 工具类，通过 classList 声明式切换`。
- `FORBIDDEN: 在客户端设置菜单中保留已交由服务端架构接管的孤立按钮 (如 JAVVerse 跳转、HUD 探针、手动触发扫描)` ➔ `USE: 严格恪守职责边界，客户端只负责 WebDAV 写入 .strm，无关管理项坚决清除`。
- `FORBIDDEN: 要求用户手动复制和粘贴内部 Token` ➔ `USE: 移交同源 API 自动感知或在访问站点时无感签发，设置界面彻底屏蔽手动 Token 输入框`。
