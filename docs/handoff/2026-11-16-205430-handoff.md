## 2. 本阶段完成的核心成果

### 2.1 纯函数片段胶囊状态机引擎 (`src/player/managers/capsuleStateMachine.js`)
- 定义 5 态互斥主状态（优先级严格递减）：
  - `editing` (`CAPSULE_STATES.EDITING`) > `looping` (`CAPSULE_STATES.LOOPING`) > `inside` (`CAPSULE_STATES.INSIDE`) > `near` (`CAPSULE_STATES.NEAR`) > `idle` (`CAPSULE_STATES.IDLE`)
- 定义草稿胶囊 4 态：
  - `draft-empty` / `draft-a-marked` / `draft-ready` / `draft-editing` (`evaluateDraftCapsuleState`)
- **人机工学非对称邻近窗口与短视频自适应**：
  - `PROXIMITY_CONFIG`：`NEAR_LEAD_SEC = 6.0`、`NEAR_TRAIL_SEC = 4.0`、`HYSTERESIS_SEC = 1.5`、`HIGHLIGHT_HIT_LEAD_SEC = 1.5`、`HIGHLIGHT_HIT_TRAIL_SEC = 3.0`、`PRIMARY_SWITCH_HYSTERESIS_SEC = 1.2`
  - `getAdaptiveProximityWindows(duration)` 对 `< 24s` 超短视频按比例收窄窗口
- **唯一主焦点 (`isPrimary`) 裁决与防抖**：
  - 按 `priorityRank` ➔ 距中心/区间距离 `distance` ➔ 区间跨度 `span`（嵌套区间时更紧凑子区间胜出）➔ 1.2s 主焦点切换滞回（避免相邻胶囊边缘来回跳动）裁决唯一 `primaryTabId`
- **多表面同步助手**：`applyCapsuleStateClasses(el, entry, { includeCompatActive, syncProgressVar })` 原子更新 `.is-idle` / `.is-near` / `.is-inside` / `.is-looping` / `.is-editing` / `.is-primary` 与 `--tab-progress`

### 2.2 播放进度双向全生命周期绑定 (`LoopManager.js` & `MarkerBottomSheet.js`)
- `LoopManager.js` 新增统一入口 `syncProximityState({ targetTime, forceCenter, skipAutoCenter })`：
  - `timeupdate`（120ms 节流 + `seeking` / `_isSeekingHighlightTab` 锁保护）实时驱动状态机；
  - 监听 `seeked`、`durationchange`、`loadedmetadata`，以及 `checkAndExitLoopIfOutside(targetTime)` 入口，确保**暂停拖动进度条或点击评论时间戳跳转时立即高亮与居中**；
  - 离开单点高光窗口后自动释放陈旧的 `activeTabId`，杜绝同时粘滞高亮两个不相关胶囊；
  - 仅在 `primaryTabId` 真正切换或 `forceCenter=true` 时触发纯横向居中，避免每帧触发 `smooth` scroll 抖动；
  - `renderTabs()` 与 `renderProgressMarkers()` 原生透传当前状态机快照，并在 `cleanup()` 完整注销所有监听器与定时器。
- **GPU 进度填充与无遮挡循环徽章**：
