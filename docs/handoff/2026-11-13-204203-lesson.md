# Lesson Learned - 2026-11-13-204203

## 1. 浮层防穿透总是在新组件/重构中“复发”的根因与治理

- **FORBIDDEN**: 新建或重构弹窗/预览浮窗（如 `createModal`、`CommentCodePreview`）时自行手写零散 `stopPropagation`，把浮窗挂在局部 `overflow: hidden` / 低 `z-index` 容器（`.tm-comments-panel`）内，或使用 `pointerdown` / `touchstart` capture 监听浮层外点击立即 `hide()`。
- **USE**:
  1. 所有浮层必须挂载在 `.tm-player-container` 顶层，并向 `UISurfaceMachine` 注册（`pushModal`/`popModal` 或 `SURFACE_TYPES.*`），从而激活 `[data-has-overlay="true"]` 阻断底层 `.tm-video-wrapper`；
  2. 统一调用 `UISurfaceMachine.bindOverlayGuard(el)` 屏蔽全量 touch/pointer/mouse/click/wheel/contextmenu 冒泡；
  3. 点击外部关闭一律用 `click` capture（严禁用 `pointerdown`/`touchstart` 触发瞬间销毁），并在关闭后激活 `380ms` 全局冷却（`isWithinDismissCooldown()` / `.is-overlay-cooldown`），彻底消除移动端的“点击释放延迟穿透”；
  4. 通过 `scripts/compliance-lint.js` `[6/6]` 静态门禁在每次 `ci:check` 中自动拦截违规代码，不依赖人工记忆。

## 2. 评论“看似必须等爬虫完才展示”的三重管线陷阱

- **FORBIDDEN**:
  1. 在 `loadComments(1)` 中只调用同步 `CommentCacheManager.hasValidCache()` 而忽略冷启动阶段尚未回填内存的 `await CommentCacheManager.getAsync()`（IndexedDB）；
  2. 在 `loadComments(1)` 里 `await SupabaseService.fetchComments()` 后再 `await WebDavClient.downloadBackup()`，最后才发起源站爬虫；
  3. 在 `loadSiteComments(siteKey, 1)` 开头无条件重置 `site.comments = []` 且在爬虫 `catch` 中再次清空 `site.comments = []`。
- **USE**:
  1. `loadComments(1)` 先 L1 同步命中 → 再 `await getAsync()` 读取 IndexedDB（命中即刻展示并跳过网络）；
  2. 未命中本地缓存时，立即渲染分区骨架，同时并发竞速启动 Supabase、WebDAV 独立文件与源站爬虫，任意渠道先返回即局部增量合并且立即 `renderCommentsList()`；
  3. `loadSiteComments(1)` 若检测到已有云端/WebDAV 预加载评论，绝不清空原有列表；源站失败时保留已预加载评论并维持 `status = 'loaded'`。
