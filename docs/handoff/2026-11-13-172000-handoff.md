# Handoff: 移动端评论时间戳收藏免长按、±5s 全几何判重与正式落盘闭环

- **日期时间**: 2026-11-13 17:20:00
- **版本号**: `v5.7.118-beta.022`
- **当前 Git 分支**: `dev`
- **主要工作目标**:
  1. 解决评论区时间戳在移动端无法使用 hover 收藏、用户不愿长按或进行多步繁琐操作的问题；
  2. 实现时间戳与用户已有片段列表 (tabs) 进行相近内容（前后 5 秒）比对，若已收藏则主动点亮右侧收藏按钮与胶囊背景，提示用户已收藏；
  3. 修复点击收藏按钮仅添加草稿态、刷新即失的架构缺陷，实现正式入库与持久化落盘 (`addTabFromTime`)；
  4. 消除移动端 350ms 长按展开时间胶囊定时器与手势冲突。

---

## 🛠️ 成果与改动拓扑

1. **全几何相交与边界判定引擎 (`src/player/comments/CommentDataPipeline.js`)**:
   - 实现并导出 `checkIsTimestampFavorited(targetSecs, tabs, threshold = 5)`：
     - **[点 vs 点]**: 绝对差值 `|startTime - sec| <= 5s` 命中；
     - **[点 vs 区间]**: 点落在区间内部或区间两端延展 `[startTime - 5, endTime + 5]` 命中；
     - **[区间 vs 单点]**: 单点落在评论区间的 `[secStart - 5, secEnd + 5]` 命中；
     - **[区间 vs 区间]**: 两区间存在相交重叠，或两区间端点距离 `<= 5s` 命中。
   - `highlightCommentText` 强化：支持传入 `{ tabs }` 预先执行几何比对，渲染时直接预注入 `.is-favorited` 状态类、实心金星 (★) 以及精准提示 `title="此时间已在片段列表中 (误差 ≤ 5s)"`。
   - `processComment` 强化：增加第四参数 `options = {}` 并透传至 `highlightCommentText`。

2. **接口转发与桥接 (`src/player/controls/CommentScraper.js`)**:
   - 转发导出 `checkIsTimestampFavorited`。

3. **控制面板与交互闭环 (`src/player/controls/CommentPanel.js`)**:
   - `handleStarClick(secs, link)`：
     - 若 `link.classList.contains('is-favorited')`：触发触觉震动并 Toast 提示 `该时间已在片段列表中 (误差 ≤ 5s)`，同时保持播放跳转，绝不重复生成冗余片段；
     - 若未收藏：从卡片提取评论纯文本摘要（前 40 字），优先调用 `LoopManager.addTabFromTime(secs, commentExcerpt)` 正式入库落盘，乐观添加 `is-favorited` 类并更新 `title`，Toast 提示收藏成功；
   - `handleTimeClick(secs, link)`：点击时间文字跳转播放时，若已收藏则在 Toast 中标注 `(已在片段列表中)`；
   - **彻底移除针对 `jc-time-link` 的 350ms 长按定时器**：仅保留番号链接 `jc-code-link` 的 400ms 长按预览，消除移动端所有手势阻塞与延时；
   - `updateFavoriteBadges()` 彻底移除历史错误的 `jc-time-add-badge` 阻断，全面遍历 `.jc-time-link` 并接入 `checkIsTimestampFavorited(secs, tabs, 5)`。

4. **触屏与桌面双轨 CSS 规范 (`src/player/ui/styles/02_components/_comments.css`)**:
   - **移动端触屏媒体查询 (`@media (hover: none) and (pointer: coarse)`)**:
     - `.jc-time-link`：内边距微调为 `2.5px 5px 2.5px 6.5px`，`box-sizing: border-box`，`overflow: hidden`，绝无负外边距碰撞风险；
     - `.jc-time-star-btn`：内嵌常驻紧凑展示（`max-width: 20px; opacity: 0.45; margin-left: 3px; pointer-events: auto;`），手指轻点即收藏；轻触即时放大 `transform: scale(1.22)` 弹性反馈；
   - **桌面端媒体查询 (`@media (hover: hover) and (pointer: fine)`)**:
     - 保持未 hover 时 0 宽度隐藏，鼠标移上胶囊时平滑滑出展示空心五角星；
   - **已收藏状态常驻点亮 (`.jc-time-link.is-favorited`)**:
     - 胶囊采用温润琥珀金底色 `hsla(38 92% 50% / 0.16)`、边框 `hsla(38 92% 50% / 0.35)` 与文字 `#f59e0b`；
     - 内嵌五角星隐藏空心星、常驻展示高饱和实心金星 (★)，全端常驻点亮；
   - 彻底删除历史遗留且含义混乱的 `.show-star-btn` 规则。

5. **CI 门禁与自动化单元测试 (`tests/mobile-timestamp-favorite.test.mjs`)**:
   - 包含 4 大类完整断言：
     1. `checkIsTimestampFavorited` 全几何判定场景（单点vs单点、单点vs区间、区间vs单点、区间vs区间、越界与防御性测试）；
     2. `highlightCommentText` 预判渲染与已收藏点亮；
     3. CSS 规范与触屏免长按、桌面 hover、无 `.show-star-btn`；
     4. `CommentPanel.js` 逻辑完整性与 `addTabFromTime` 落盘闭环；
   - 已无缝挂入 `scripts/ci-test.js`。
