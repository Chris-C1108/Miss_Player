# Session Lessons & Anti-Patterns: PC 横屏分栏丢失与控制面板吸附隐退综合治理

- Date & Time: 2026-10-14 18:07:01
- Focus Module: CSS 响应式架构层 (`_landscape_pc.css`, `_comments.css`)、UI 管理器 (`UIManager.js`) 与 拖拽状态机 (`DragManager.js`)

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
- **现象表现 1**：在 PC 横屏分栏（视口宽 ≥ 930px）下，左侧视频正常，但右侧本应出现的侧边栏（评论区）整块变成红黑底色空槽，且顶部的退出/设置/折叠按钮完全消失，视频正上方孤悬标题。
- **现象表现 2**：控制面板吸附嵌入到侧边栏（Docked-BR）失效，呈现为带有外边距与圆角的悬浮卡片漂在右下角，强行遮挡评论区底部的 Comment 输入框与操作按钮。
- **现象表现 3**：吸附嵌入后，用户无法按住拖走控制面板；且在静置 3 秒后控制面板被错误当成悬浮窗自动隐退（淡出消失）。
- **触发条件**：Phase 14 移除 `_landscape_pc.css` 中的 `!important` 后，在桌面端浏览器打开视频页面。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
- **全局媒体查询反噬**：远古版本在 `_comments.css` 中遗留了带有 10 处 `!important` 的 `@media (orientation: landscape) { .tm-comments-panel { display: none !important; width: 0 !important; visibility: hidden !important; } }`。旧架构中因 `_landscape_pc.css` 充斥 `!important` 形成“毒素对冲”；重构降噪后，该全局规则凭借 `!important` 特异度反向压倒 PC 横屏分栏规则，将评论区与内嵌的按钮栏连根拔除。
- **Grid 弹性拉伸与绝对定位冲突**：在父容器为 Grid（`grid-template-rows: minmax(0, 1fr)`）的环境下，子项的 `height: calc(100% - var(--height))` 与 `margin-bottom` 因百分比无法确定解析而死锁为 `0px`，无法让出底部空间；同时 `DragManager.js` 吸附后未清理行内 `style.left/top` 绝对像素值，特异度压倒 CSS 规则，导致错位溢出。
- **手柄误杀与隐退状态脱节**：错误地在吸附态将拖动手柄 `display: none` 阻断了事件源；`autoHideControls` 未将吸附停靠态排除在 3 秒自动隐退逻辑之外。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **纯净组件层职责**：彻底剔除 `_comments.css` 中的全局横屏隐藏规则，将设备与视口响应式适配 100% 收拢至 `_landscape_pc.css`。
2. **安全区 Padding 避让**：将侧栏避让机制由失效的 `margin-bottom` 升级为 `padding-bottom: var(--docked-controls-height)`，实现内部元素平滑推起，物理 0 遮挡。
3. **吸附时 JS 行内样式归零**：在 `DragManager.js` 的 `updateDockedState` 中，一旦判定停靠，立即执行 `left = ''; top = ''; bottom = ''; right = ''; transform = '';`，将控制权 100% 交还给 CSS 规范。
4. **保留交互触点与常驻守卫**：保留 `.tm-control-drag-handle` 显示，并在 `UIManager.js` 的 `autoHideControls` 与 `hideControls` 中注入 `isDocked` 拦截，停靠态常驻不隐退。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN: 在业务组件样式（如 `_comments.css`）中私自编写全局跨视口的 `@media (orientation: landscape)` 隐藏规则 -> USE: 严格遵从双轨分层拓扑，横屏及视口分栏样式一律收敛至 `03_responsive/_landscape_pc.css` 统一调度。
- FORBIDDEN: 在 CSS Grid 弹性单元格（`1fr`）子容器中使用 `margin-bottom: var(--h)` 或 `height: calc(100% - var(--h))` 试图给底部悬浮元素让位 -> USE: 使用容器内部安全边距 `padding-bottom: var(--h)` 搭配 `box-sizing: border-box` 进行流式推起。
- FORBIDDEN: 在 JS 拖拽组件进入状态类吸附停靠（Docked State）后，继续保留 DOM 上的行内定位样式（`style.left`, `style.top`） -> USE: 进入状态类调度时立即清空所有行内绝对坐标（置为空字符串），让 CSS 规则原生接管。
- FORBIDDEN: 为了视觉纯净而简单粗暴地将吸附态元素的拖动手柄设置为 `display: none` -> USE: 保留低视觉侵略性的微缩指示手柄，确保手势交互触点不丢失。
- FORBIDDEN: 在全屏观影或自动隐退逻辑中将侧边栏底端的常驻嵌入面板误判为悬浮窗一同隐藏 -> USE: 无论 JS 定时器还是 CSS 规则，必须通过 `:not([class*="tm-controls-docked-"])` 与 `isDocked` 状态守卫对停靠态进行豁免常驻。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- RULE: 动静分离与状态停靠契约 (FORBIDDEN: Retaining inline style left/top during docked states -> USE: Clear inline geometry styles upon docking and manage bottom/right via CSS state classes)
