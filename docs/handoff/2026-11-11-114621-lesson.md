# Session Lessons & Anti-Patterns: 跨标签并发静音冲突、心跳轮询损耗与离散重入网关避坑总账

- Date & Time: 2026-11-11 11:46:21
- Focus Module: `VolumeController` / `PlayerCore` / `PlaybackSection` / `tests/volume.test.mjs`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **多标签页并发静音实时广播的破坏性打断（Eager Broadcast Clash）**：
   - 现象：在多标签页场景下，若采用基于 `BroadcastChannel` 或 `window.storage` 事件的即时广播机制，用户在 Tab B 点击静音，Tab A 正在全神贯注观看的视频音频会被瞬间强行掐断，导致灾难级的观影体验断裂；
   - 根因：混淆了“单标签自治操作”与“全局防打扰意图”的生效边界，未对前台活跃播放状态设立物理隔离豁免。
2. **高频轮询定时器的移动端资源吞噬（Heartbeat Timer Anti-Pattern）**：
   - 现象：初始草案中采用 30 秒 `setInterval` 定时器不断写入 storage 刷新时间戳；
   - 根因：高频定时器导致移动端（iOS WebKit / Android）无法进入深度休眠，频繁触发垃圾回收（GC）与无谓的持久化 I/O，严重消耗电池寿命与性能。
3. **冷启动与后发静音意图的时序冲突（Orderless Global State）**：
   - 现象：仅用单一的 `lastUnmutedTime` 记录状态，当用户在 Tab B 执行主动静音后切回 Tab A，Tab A 无法判断“外部的主动静音”是否晚于“本标签上次播放”，导致要么误切有声、要么误静音；
   - 根因：缺少对“主动静音意图（`lastExplicitMuteTime`）”的独立时序记录，导致无法完成因果时序（Causal Ordering）的判定。
4. **遗留死代码与 Autoplay 交互解冻冲突**：
   - 现象：历史遗留的 `PlayerCore.options.startMuted = false` 从未生效却散落各处；同时浏览器 Autoplay 被拒后的用户交互解冻钩子（`unmuteOnInteract`）盲目依赖 `isDefaultMutedEnabled`，绕过了 5 分钟租约机制。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **跨标签状态机的张力本质**：跨标签数据共享与单标签独立交互之间存在天然的张力。用户在一个标签页主动静音，通常代表其物理环境（如有人走近、夜深）需要安静，这种意图具有全局扩散性；但**绝不可侵入破坏当前用户正在前台观看的独立内容**。
2. **重入断点的离散性（Discrete Re-entry）**：状态同步的合理生效时机不在“操作发生的瞬间”，而必须在各标签页“重新进入播放器（切回前台、唤醒视窗、冷启动）”的离散重入网关（Re-entry Gates）上被动触发与惰性结算。
3. **时序因果律判定缺失**：单凭 `now - lastUnmutedTime >= lease` 只能判定 TTL 超时，无法捕获“在此期间外部发生的更高优先级主动静音意图”。必须引入双时间戳账本进行标量时序判定。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **有声租约机制（Audible Lease Pattern with TTL）彻底消灭定时器**：
   - 废除任何 `setInterval` 心跳；
   - 仅在离散生命周期钩子（播放、暂停、切后台 `visibilitychange: hidden`、关闭播放器 `close()`、卸载 `beforeunload`）记录时间戳；
   - 离开时若有声，记录 `lastUnmutedTime = Date.now()`；若静音，记录 `lastUnmutedTime = 0`，将运算成本完全收敛至 0。
2. **活跃播放豁免权（Active Playback Exemption）**：
   - 凡处于前台可见视窗中正常播放的视频，拥有绝对音频自治权，严禁接收任何外部标签页的即时静音广播，彻底消除多标签误伤。
3. **三道离散重入网关（Re-entry Gates）**：
   - **Gate 1**: 页面切回前台（`document.visibilityState === 'visible'`）触发 `onReentry()`；
   - **Gate 2**: 播放器从收起态重新唤醒呼出；
   - **Gate 3**: 新开标签页冷启动初始化。
4. **后发主动意图覆盖算法（Later Explicit Intent Supersedes）**：
   - 记录 `lastExplicitMuteTime`（全网最近一次主动点击静音的时间戳）；
   - 在各重入网关执行确定性判定：
     ```javascript
     // 1. 全局租约超时 -> 静音
     if (now - lastUnmutedTime >= leaseMs) return true;
     // 2. 外部主动静音晚于取消静音 -> 全局已被覆盖，静音
     if (lastExplicitMuteTime > lastUnmutedTime) return true;
     // 3. 外部主动静音晚于当前标签上次有声时刻 -> 继承外部防打扰意图，静音
     if (lastExplicitMuteTime > 0 && localAudibleTime > 0 && lastExplicitMuteTime > localAudibleTime) return true;
     // 4. 处于租约内且外部无后发静音 -> 保持有声连贯观影
     return false;
     ```

## 4. FORBIDDEN ANTI-PATTERNS & MANDATES (成对避坑禁令)
- `FORBIDDEN: 使用 setInterval/setTimeout 轮询心跳刷新持久化存储 -> USE: 纯事件驱动有声租约模型 (Audible Lease Pattern)，仅在播放、暂停、切后台与退出断点落盘`。
- `FORBIDDEN: 使用 BroadcastChannel 或 storage 事件向其他正在播放的标签页强行广播静音 -> USE: 确立活跃播放自治豁免权 (Active Playback Exemption)，意图同步且只能在重入网关 (Re-entry Gates) 惰性结算`。
- `FORBIDDEN: 用单一布尔值或单一时间戳表征多标签音频状态 -> USE: 双时间戳账本 (lastUnmutedTime + lastExplicitMuteTime) 进行后发意图因果判定`。
- `FORBIDDEN: 在用户交互解冻 (unmuteOnInteract) 时粗暴无条件取消静音 -> USE: 统一接入 checkShouldDefaultMute(playerState) 综合决策`。

## 5. AGENTS.MD RULE EXTRACTION (准备回填的系统宪法准则)
```markdown
### 8. 跨标签状态租约与离散重入网关准则 (Multi-Tab Lease & Re-entry Gate Protocol)
- **活跃播放自治豁免**：正在前台正常播放的视听媒体享有最高自治权，严禁使用 BroadcastChannel 或 storage 跨标签强行打断正在播放的内容；
- **零轮询有声租约**：严禁采用定时器心跳刷新音频状态，一律采用 Audible Lease 模式，仅在切后台、暂停与退出时原子落盘；
- **离散重入网关**：跨标签防打扰与静音继承必须且只能在离散重入网关（切回前台 `visibilitychange: visible`、播放器唤醒、冷启动）由判定引擎惰性结算。
```
