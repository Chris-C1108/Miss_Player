# 🎬 Miss Player | シネマモード · 片手操作Web動画プレーヤー

[中文](README.md) | [English](README-EN.md) | **日本語** | [한국어](README-KO.md)

> **モバイル片手操作と極上の動画視聴体験のために設計。ポップアップ広告や小さすぎる画面でのストレスから解放。有識者コメント内のハイライトタイムスタンプへワンタップ直行、お気に入りシーンの無限ループ再生、マルチデバイス自動クラウド同期に対応！**

---

### 💡 なぜ Miss Player が必要なのか？
スマートフォンやPCのブラウザでWeb動画を視聴する際、以下のような悩みはありませんか？
- 📱 **スマホ縦画面の動画が小さすぎる**：上下に巨大な黒帯や不要なレコメンドが表示され、両手で持ち続けると疲れる。
- 🛑 **ポップアップ広告の嵐**：1回タップするだけで別タブが3つも開き、誤操作のストレスが絶えない。
- ⏩ **見どころ探しが手探り**：シークバーを手探りで動かして時間を無駄にし、一番のハイライトを見逃してしまう。
- 🔁 **お気に入りシーンの繰り返し再生が面倒**：手動で何度もシークバーを巻き戻すのが非常に煩わしい。
- 💻 **複数デバイス間で非同期**：PCでマークしたお気に入りタイムスタンプが、スマホに持ち替えると消えている。

**Miss Player はこれらすべての課題をワンタップで解決します！**

---

## 🌟 主な機能

### 1. 📱 シネマ級「片手モード」— 縦持ちスマホの決定版
- **フルスクリーン没入視野**：画面下部のピンクのカプセル型フローティングボタンをタップするだけで、映画館のような没入型プレーヤーに瞬時に切り替わります。
- **自由パニング & Minimap レーダー**：スマートズーム＆自動中央配置。親指で画面を軽くスワイプするだけで上下左右に自由に視点を移動可能。下部のホワイトバーハンドルと心地よい触覚フィードバックで直感的に操作できます。
- **超高速ジェスチャー操作**：
  - **長押しで加速**：画面の任意の場所を長押しするだけで 2倍速 / 3倍速 再生；
  - **ダブルタップで再生/一時停止**：すばやく2回タップして直感的に再生切替；
  - **下スワイプでスマート終了**：親指を下へスワイプするだけでスムーズにプレーヤーを終了。

### 2. 💬 サイト横断コメント集約 & スマートハイライトタイムスタンプ — もう無駄な早送りは不要
- **マルチソースリアルタイム取得**：Jable、JavDB、JavLibrary など、Web上の有識者・熟練ユーザーによるリアルな人気コメントを一括集約。
- **AI級スマートノイズフィルター**：数十種類の強力なフィルタリングルールを内蔵し、スパム広告や誘導リンク、無駄な書き込みを自動排除。価値の高いストーリー解説や見どころコメントだけを抽出します。
- **ハイライトタイムスタンプへワンタップ直行**：
  - コメント内のあらゆる時間表記（例：`12:35`、`34分20秒`、`1:05:20`）を自動認識；
  - 自動的に**ハイライト付きジャンプカプセル**に変換し、タップするだけで該当シーンへ瞬時にテレポート；
  - おすすめのハイライト区間をワンタップで A-B ループ再生セグメントに登録可能！

### 3. 🔁 A-B ループ & マルチマーカーシステム — 復習・研究に最適
- **シームレス A-B ループ**：開始点と終了点をワンタップで設定し、お気に入りのシーンを途切れず何度でもループ再生。
- **カラフルピルタブ管理（Pill Tabs）**：1本の動画に複数のマーカーを設定可能。カスタムラベル、カラー分類、ミリ秒単位の微調整に対応。
- **ドロワー型マーカーマネージャー（Bottom Sheet）**：画面下部から上へスワイプすれば、いつでも全マーカーリストを呼び出して瞬時に切り替え可能。

### 4. ☁️ WebDAV マルチデバイス スマートクラウド同期 — スマホ / PC / タブレットのシームレス連携
- **全プラットフォーム設定 & マーカー同期**：Nutstore（堅果云）、Alist、Nextcloud、Nginx など、標準的な WebDAV サービスに完全対応。
- **CRDT 分散スマートマージ**：PCで登録したハイライトタイムスタンプは、25秒以内にスマホ側へ自動かつバックグラウンドで同期。30日間のトゥームストーン（墓碑）削除同期メカニズムを内蔵。
- **デバイス最適化分離**：PCでは右側コメントバーを展開状態に保ち、スマホでは純粋な片手モードを維持。デバイスごとのUI設定が干渉しません。

### 5. ⚡ Web サイト特権 & 超高速・快適強化
- **強力広告ブロック**：ポップアップ広告、ハイジャックリダイレクト、埋め込みバナーを徹底排除。
- **アカウント自動ログイン**：複数ドメインの認証情報を記憶し、毎回のパスワード入力を省略。
- **自動最高画質選択**：ロード時に最適な 1080P/4K 高ビットレート画質を自動選択。
- **動画情報・タイトルの自動展開**：概要欄、出演者情報、長いタイトルも省略なしで一目で把握。
- **バックグラウンド/フォーカス喪失時の自動一時停止**：別タブへの切り替えやバックグラウンド移行時に自動で消音・一時停止（設定でON/OFF可能）。

## 🚀 パフォーマンスと体験：iOS ネイティブアプリのような滑らかさ
- ⚡ **ミリ秒級の応答性（INP < 3ms）**：フローティングボタンをタップした瞬間に起動、遅延ゼロ。
- 🎯 **画面のガタつきゼロ（CLS 0.00）**：プレースホルダー技術を採用し、プレーヤー起動・終了時にもWebページが上下にガタつきません。
- 🍎 **iOS Safari 徹底最適化**：システム全画面の誤作動を防ぎ、iPhone の Dynamic Island や下部 Safe Area（セーフエリア）に完全対応。

## 🛠️ インストールと利用ガイド

### 📱 Apple デバイス (iOS / iPadOS)
1. **推奨方法 1**：App Store から [Stay for Safari](https://apps.apple.com/jp/app/stay-for-safari-%E3%83%96%E3%83%A9%E3%82%a6%E3%82%b6%E3%81%ae%E4%bc%b4%E4%be%a3/id1591620171)（無料版でOK）をインストールし、スクリプト配布ページからインストール。
2. **推奨方法 2**：App Store から [Userscripts](https://apps.apple.com/jp/app/userscripts/id1463298887) 拡張機能をインストールして利用。

### 🤖 Android デバイス
- **Via ブラウザ**、**Kiwi ブラウザ**、**Firefox**、または **Edge** に [Tampermonkey (油猴プラグイン)](https://www.tampermonkey.net/) をインストール後、本スクリプトをワンクリックでインストール。

### 💻 デスクトップ PC (Windows / macOS)
- Chrome / Edge / Firefox / Safari に [Tampermonkey](https://www.tampermonkey.net/) または [ScriptCat](https://scriptcat.org/) を導入することで、大画面で快適にご利用いただけます。
