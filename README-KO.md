# 🎬 Miss Player | 시네마 모드 · 한손 조작 웹 동영상 플레이어

[中文](README.md) | [English](README-EN.md) | [日本語](README-JA.md) | **한국어**

> **모바일 한손 조작과 최고의 영상 감상 경험을 위해 설계되었습니다. 팝업 광고와 답답하게 작은 화면에서 벗어나세요. 베테랑 유저들의 핵심 하이라이트 타임스탬프 원클릭 이동, 명장면 무한 A-B 루프 재생, 기기 간 자동 클라우드 동기화까지 완벽 지원!**

---

### 💡 왜 Miss Player가 필요한가요?
스마트폰이나 PC 브라우저로 웹 동영상을 시청할 때 이런 불편함을 겪은 적이 있으신가요?
- 📱 **스마트폰 세로 화면이 너무 작음**: 상하단에 거대한 여백과 불필요한 추천 피드만 가득해 두 손으로 들고 보기 피로함.
- 🛑 **쉴 새 없는 팝업 광고**: 한 번 터치하면 탭이 3개씩 열리는 무단 리디렉션과 잦은 오작동 스트레스.
- ⏩ **하이라이트 구간 찾기의 번거로움**: 탐색 바를 무작위로 넘기며 시간을 낭비하다 명장면을 놓침.
- 🔁 **좋아하는 장면 반복 재생의 귀찮음**: 탐색 바를 수동으로 계속 되감아야 하는 번거로움.
- 💻 **기기 간 북마크 미동기화**: PC에서 체크해 둔 명장면 타임스탬프가 모바일로 전환하면 사라짐.

**Miss Player는 클릭 한 번으로 이 모든 문제를 해결합니다!**

## 🌟 주요 핵심 기능

### 1. 📱 시네마급 「한손 모드」 — 세로 그립의 혁신
- **몰입형 전체화면 뷰포트**: 하단의 핑크 캡슐 플로팅 버튼을 터치하여 극장급 몰입형 플레이어로 즉시 전환.
- **자유로운 팬(Pan) 이동 & Minimap 미니맵 레이더**: 스마트 줌 및 자동 중앙 정렬. 엄지손가락으로 화면을 가볍게 슬라이드하여 상하좌우 자유롭게 시야를 이동하고, 하단 화이트 핸들 바와 햅틱 피드백으로 직관적으로 컨트롤.
- **초고속 제스처 인터랙션**:
  - **길게 눌러 가속**: 화면 어디든 길게 누르면 2배속 / 3배속 재생 발동;
  - **더블 탭으로 재생/일시정지**: 두 번 톡톡 탭하여 빠르게 재생 전환;
  - **아래로 스와이프하여 나가기**: 엄지손가락으로 가볍게 아래로 내리면 부드럽게 플레이어 종료.

### 2. 💬 멀티 플랫폼 베스트 댓글 통합 & 스마트 하이라이트 타임스탬프 — 무의미한 탐색 끝
- **멀티 소스 실시간 수집**: Jable, JavDB, JavLibrary 등 웹 전반의 신뢰도 높은 베스트 댓글 실시간 수집.
- **AI급 스마트 노이즈 필터링**: 수십 가지 필터링 룰을 내장하여 스팸 광고, 낚시성 링크, 무의미한 도배글을 자동 제거하고 핵심 스토리 리뷰 및 하이라이트 정보만 엄선.
- **하이라이트 타임스탬프 원클릭 이동**:
  - 댓글 내 모든 시간 표기(예: `12:35`, `34분 20초`, `1:05:20`)를 지능적으로 감지;
  - **하이라이트 바로가기 캡슐**로 자동 변환되어 클릭 한 번에 해당 구간으로 즉시 텔레포트;
  - 추천 하이라이트 구간을 원클릭으로 A-B 루프 반복 구간으로 바로 등록 가능!

### 3. 🔁 A-B 구간 루프 & 다중 마커 시스템 — 명장면 복습과 연구에 최적
- **매끄러운 A-B 구간 반복 재생**: 시작점과 종료점을 원터치로 지정하여 끊김 없이 명장면을 무한 루프 감상.
- **컬러풀 필 탭(Pill Tabs) 마커 관리**: 영상 하나에 여러 개의 마커 포인트를 추가하고 라벨 설정, 색상 분류, 밀리초 단위 미세 조정 지원.
- **드로어형 마커 매니저 (Marker Bottom Sheet)**: 화면 하단에서 위로 스와이프하여 언제든 마커 목록을 불러오고 즉시 전환.

### 4. ☁️ WebDAV 스마트 다중 기기 클라우드 동기화 — 스마트폰 / PC / 태블릿 끊김 없는 연동
- **전 플랫폼 설정 및 마커 동기화**: Nutstore(坚果云), Alist, Nextcloud, Nginx 등 모든 표준 WebDAV 서비스와 완벽 호환.
- **CRDT 기반 분산 스마트 머지**: PC에서 저장한 타임스탬프가 25초 이내에 모바일 기기로 백그라운드 자동 수집; 30일 툼스톤(Tombstone) 삭제 동기화 메커니즘 내장.
- **기기별 폼팩터 맞춤 분리**: PC는 우측 댓글 사이드바를 펼친 상태로 유지하고, 모바일은 순수 한손 모드를 유지하여 기기 간 UI 충돌 방지.

### 5. ⚡ 웹사이트 권한 & 쾌적한 감상 부스팅
- **강력한 광고 차단**: 팝업창, 악성 리디렉션, 내장 배너 완벽 차단.
- **계정 자동 로그인**: 다중 도메인 계정 정보를 기억하여 반복 입력 번거로움 해소.
- **자동 최고화질 재생**: 로드 즉시 1080P/4K 고비트레이트 고화질 우선 선택.
- **영상 정보 및 제목 자동 확장**: 영상 설명, 출연진 정보, 긴 제목을 한눈에 확인.
- **백그라운드 전환/포커스 아웃 시 자동 일시정지**: 다른 탭으로 이동하거나 백그라운드 전환 시 자동 음소거 및 일시정지 (설정에서 변경 가능).

## 🚀 성능 및 사용자 경험: iOS 네이티브 앱 수준의 부드러움
- ⚡ **밀리초급 응답 속도 (INP < 3ms)**: 플로팅 버튼을 누르는 즉시 지연 없이 플레이어 실행.
- 🎯 **화면 흔들림 제로 (CLS 0.00)**: 원위치 플레이스홀더 기술을 적용하여 플레이어 온/오프 시 웹페이지가 위아래로 덜컹거리지 않음.
- 🍎 **iOS Safari 완벽 최적화**: 시스템 전체화면 오작동을 방지하고 iPhone Dynamic Island 및 하단 Safe Area(안전 영역)에 완벽 대응.

## 🛠️ 설치 및 사용 가이드

### 📱 Apple 기기 (iOS / iPadOS)
1. **추천 방법 1**: App Store에서 [Stay for Safari](https://apps.apple.com/kr/app/stay-for-safari-%EB%B8%8C%EB%9D%BC%EC%9A%B0%EC%A0%80-%EB%8F%99%EB%B0%98%EC%9E%90/id1591620171)(무료 버전 사용 가능)를 설치한 후, 스크립트 배포 페이지에서 원클릭 설치.
2. **추천 방법 2**: App Store에서 [Userscripts](https://apps.apple.com/kr/app/userscripts/id1463298887) 확장 프로그램을 설치하여 사용.

### 🤖 Android 기기
- **Via 브라우저**, **Kiwi 브라우저**, **Firefox**, 또는 **Edge** 브라우저에 [Tampermonkey 확장 프로그램](https://www.tampermonkey.net/)을 설치한 후 스크립트를 설치하세요.

### 💻 데스크톱 PC (Windows / macOS)
- Chrome / Edge / Firefox / Safari에 [Tampermonkey](https://www.tampermonkey.net/) 또는 [ScriptCat](https://scriptcat.org/)을 설치하여 대화면으로 쾌적하게 감상하세요.
