## 3. 下一阶段建议任务 (For Next Session)

尽管 5 个主阶段已达成，后续开发可针对以下深度细节进一步打磨：

   - 在 Jable (`jable.tv`)、JAVLibrary 等站点实机验证 `MediaSniffer` 对分段流的嗅探与播放稳定性；
   - 验证暗黑主题切换与不同分辨率（特别是移动端竖屏 iOS Safari）下的跟手性。
2. **多标签页跨窗口联动体验测试**
   - 开启两个不同影片标签页，测试 `ReactiveStore` 修改设置（如隐藏控制栏、切换音效）时多窗口的即时同步效果；
   - 测试 A-B 点打点切片写入 `IndexedDB` 后的离线持久化与历史回放。
3. **正式发版标签打标发布 (Release)**
   - 后续有正式版本发布需求时，遵循标准命令：
     `npm run ci:check` -> 递增版本号三处 -> `git tag v5.6.22 && git push origin v5.6.22` 触发 Actions 自动打包发布。
