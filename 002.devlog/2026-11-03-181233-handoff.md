## 1. COMPLETED OBJECTIVES (已完成工作)
- [x] **iOS WebKit 虚拟键盘适配与双重偏移根治**：
  - 彻底理清并消除了 `visualViewport` 与宿主 `window.scrollY` 在 iOS 软键盘弹出时的双重挤压（Double-Shift Offset）冲突；
  - 建立了宿主滚动锁定守卫（`window.scrollTo(0,0)` 瞬时锁定）与 Shadow DOM 视口自适应底栏体系。
- [x] **打点即时修改弹窗重构 (`tm-inline-remark-popover`)**：
  - 解决人体工学缺陷，从天花板（`top: 84px`）下移至底栏与软键盘自然衔接区（`bottom: calc(var(--keyboard-height, 0px) + 76px)`）；
  - 突破 iOS Safari 异步聚焦安全限制，在用户点击直接调用栈内执行**同步立即聚焦**（`input.focus()` + `input.select()`），实现点击编辑光标直入输入框；
  - 解决 Shadow DOM 跨边界捕获重定向误判（`popover.contains(e.target)` 恒为 false）导致的点击输入框瞬间闪退销毁 Bug，改用 `e.composedPath().includes(popover)`。
- [x] **发评底栏完整标签选择模式复原与体验优化**：
  - 按照用户要求改回原版完整高光选择组件（`tm-comment-tag-select-modal`），嵌套于 `tm-comment-submit-bar-wrapper` 内部随输入栏平滑升降；
  - 完整呈现：复选框 + 莫兰迪彩色时间胶囊 + 独立可编辑备注框（`.tm-tag-remark-input`），支持即时预览与当场微调；
  - 彻底移除发评遮罩模糊层（`.tm-comment-backdrop { display: none; }`），确保输入时视频画面与评论区 100% 清晰可见；
  - 胶囊支持轻点即时 Seek 跳转视频进度（Click-to-Seek）；
  - 阻断列表 `touchmove` 事件冒泡，补齐 `-webkit-overflow-scrolling: touch` 与 `touch-action: pan-y`，彻底解决 iOS 无法触摸滚动的痛点。
- [x] **评论草稿实时自动暂存 (Anti-Loss Draft)**：
  - 接入以当前番号为唯一命名空间的 `sessionStorage`（`mp_comment_draft_[avcode]`），用户键入即静默暂存；
  - 退出重进自动检测还原，发表成功后原子清理，彻底杜绝意外误退导致文字丢失。
- [x] **浮动按钮生命周期全状态压制**：
  - 解决浮动按钮进入播放器后未隐藏且被定时器反复唤醒（`z-index: 2147483640` 压在控制栏之上）的缺陷；

- [x] **视口全景探针 (ViewportDebugHUD) 设置受控化**：
