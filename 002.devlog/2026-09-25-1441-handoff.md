## 📌 本轮会话完成的核心成果

1. **MissAV 预览小视频接口逆向与链路打通**：
   - 提取并验证 `fourhoi.com` 静态视频存储拓扑，建立 `{code}/preview.mp4` 与 `{code}-uncensored-leak/preview.mp4` 的主备加载与降级回退机制。
   - 在构建配置（`vite.config.mjs` 与 `webpack.config.js`）的 `@connect` 中安全补充 `fourhoi.com`。

2. **评论区番号标签交互全面升级**：
   - **PC 端悬浮 / 移动端长按**：自动弹出高质感毛玻璃预览浮窗（256 × 180 px，带居中加载动画、静音循环播放与视口边界碰撞保护）。
   - **即时复制与无感跳转**：取消繁琐的二次弹窗，点击番号直接拷贝至剪贴板（附带 Toast），点击预览浮窗中的视频直接在新标签页打开 MissAV 对应视频页。

3. **第三方宿主站跨域与防盗链 403 彻底攻克**：
   - **痛点**：在 `javrate.com` 等第三方站点，浏览器直接请求 `fourhoi.com` 会被 CORS 拦截且因携带第三方 `Referer` 被 Cloudflare 判定为盗链阻断（403 Forbidden）。
   - **终极解法**：在 `CommentPanel.js` 中使用油猴沙箱特权 API `GM_xmlhttpRequest`，携带受信标头 `Referer: https://missav.ai/` 请求二进制 `blob`，并转换为纯本地同源 `URL.createObjectURL(blob)` 注入 `<video>` 播放，配合全局请求 ID 和 `revokeObjectURL` 杜绝内存泄漏，实现任意宿主站秒级正常播放。

4. **跨站多源资源池（ResourcePoolManager）架构设计规划**：
   - 深入分析了 Jable.tv（KVS 架构基于自增 `video_id`，封面及 `preview.mp4` 静态存放在 `assets.fs1.app`）与 Supjav（第三方聚合无自建预览源）的差异。
   - 确立了以“就近原则 + 零请求优先级 + 异步映射兜底”的多源资源池规划。
