## 1. COMPLETED OBJECTIVES (已完成工作)
- [x] **视频观看热度与足迹探索引擎 (HeatmapManager)**：
  - 确立 Local-First 本地闭环，数据完全落盘原生 IndexedDB (`STORES.HEATMAP`)，遵从零 GM 大数据红线；
  - 采用 5 秒固定物理时间分桶 (`BIN_SECONDS = 5`)，长视频绝不稀释 10 秒短片段；
  - 纯物理流逝停留时长累加（0 < delta < 1.5s），彻底杜绝探路乱跳带来的假阳性高光；
  - 75% Max + 25% Avg 局部峰值保留下采样算法；
  - 引入 Cubic Smoothstep ($3t^2 - 2t^3$) 片头偏置平滑衰减，消灭开播试看虚假波峰；
  - 纯平 System Gray 纯灰色无渐变 SVG 贝塞尔曲线渲染；
  - 解耦数据采集与界面显隐：设置开关仅控制 UI 展示，后台始终静默记录。
- [x] **移动端控制手柄 (Handle) 人机工程学物理重构**：
  - 废弃引起整页 Layout Thrashing 的 `style.left`，全面升级为纯 GPU `transform: translate3d(...)`；
  - 手柄尺寸在 pointerdown 瞬间一次性缓存，高频事件零 DOM 测量；
  - 废弃 30% 固定宽度，建立基于可视视口与视频缩放倍数的动态物理宽度（Dynamic Viewport-to-Content Ratio）；
  - 画面无平移余地时绝对几何锁死居中 (`translate3d(-50%, -50%, 0)`)，根除 ResizeObserver 异源写入并发竞态导致的左右疯狂闪动；
  - 手柄组件高度由 30px 缩小至 18px，释放 40% 竖屏垂直空间，扩充隐形触控热区；
  - 彻底消除轴向排他锁死，手柄支持斜向划动与拉伸平移双轴自由连贯（无需松手重按）。
- [x] **视频 16:9 兜底 & 根除控制面板从左向中间漂移闪烁**：
  - `.tm-video-wrapper` 注入原生 `aspect-ratio: 16 / 9;` 兜底，杜绝流媒体未加载时的尺寸塌陷；
  - 移除 `.tm-control-buttons` 在 `left`, `right`, `width` 上的 transition 动画，消除首帧渲染插值漂移；
  - 热度图底边物理基线永久锁死在 9px（高度 15px），时间容器下边距放宽至 9px，彻底消灭进度条展开时向上挤压时间文字的问题。
- [x] **流媒体缓冲层与网络等待条纹动效演进**：
  - 深刻认知移动端流媒体（HLS / MediaSource）在 Seek 跳转时的内存垃圾回收（Buffer Eviction）物理特性；
  - 果断放弃不可控的静态缓冲条，升华为流媒体“缓冲等待斜向流动条纹动效 (Striped Barber-Pole Animation)”；
  - 识破 HTML5 `stalled` 事件假阳性陷阱（切片下载停歇并不代表播放卡顿）；
  - 建立 180ms 物理停滞防抖确认 + 播放头前进看门狗实时灭火机制，杜绝顺播误报条纹。
- [x] **全局暂停意图锁与开播防偷跑闭环**：
  - 识破 Shadow DOM 中 `e.stopPropagation()` 阻断宿主事件导致 `BlurPlaybackManager` 误判为网络卡顿从而在 `canplay` 自动拉起播放的底层漏洞；
  - 建立 `PlayerCore.userPauseIntent` 全局权威意图锁；
  - 在 `play`、`playing` 捕获阶段与微任务中实施硬截断，彻底解决开播阶段点击暂停后缓冲完成仍自动偷跑的顽疾。
