# Session Lessons & Anti-Patterns: CSS 盒模型溢出漏洞、触控穿透与点击穿透治理

- Date & Time: 2026-10-29 23:32:37
- Focus Module: CSS Box Model / Hit-Testing / Event Delegation / Mobile Touch Guard

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **盒模型物理溢出撑爆视口引发横向位移**：真机调试发现 `div.tm-comment-loader-graphic` 达到 `376 x 38` 像素，而父容器仅 344px，横向物理溢出 32px，导致移动端手指斜向滑动时评论区发生左右剧烈晃动；
2. **预览卡片首击被控制栏拦截消费**：点击番号预览卡片时，第一次点击没有跳转页面，而是被外层误判为“点击视频区域唤醒控制面板”，点第二次才跳转；
3. **`!important` 数量突破门禁基线**：在修复幽灵点击时新增了 4 处 `!important`，导致总数达到 102 处，被 CI 门禁检查当场阻断。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **默认 `content-box` 算术溢出陷阱**：
   - 规则 `.tm-comment-loader-graphic { width: 100%; padding: 16px; }` 未声明 `box-sizing: border-box`；
   - 浏览器按标准盒模型计算总宽为：`100% + 16px*2 = 100% + 32px`，刚好宽出 32px；
   - 父容器未声明 `overflow-x: hidden` 与 `touch-action: pan-y`，移动端浏览器被迫为其建立横向滚动轨道；
2. **事件冒泡被播放器视窗事件委托捕获**：
   - 预览卡片浮在视频区域上方，但未对自身的 `pointerdown`, `mousedown`, `touchstart`, `click` 做 `e.stopPropagation()` 冒泡阻断；
   - 播放器视窗在控制栏隐藏时将任何未被排除的点击都视为“唤醒控制栏（`showControls`）并提前返回”，导致卡片的跳转被硬生生吞噬；
3. **Shadow DOM 内部滥用 `!important` 产生反噬**：
   - 在 Shadow DOM 隔离体系内，类选择器天然具备绝对控制力，盲目添加 `!important` 不仅无益，而且会快速消耗 CI 安全预算配额。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **强约束盒模型与双层横向手势锁死**：
   - 凡有 `width: 100%` 且带 `padding` 的容器，**一律显式补齐 `box-sizing: border-box; max-width: 100%;`**；
   - 在 `.tm-comment-section` 与 `.tm-comment-section-body` 上全面注入 `overflow-x: hidden; touch-action: pan-y; overscroll-behavior-x: none;`；
   - 为骨架屏 `.mp-comments-loading` 显式设置 `pointer-events: auto;` 杜绝事件击穿至底层宿主网页；
2. **浮层组件事件全生命周期硬隔离与白名单豁免**：
   - 浮层容器自身拦截所有底层指针事件冒泡（`pointerdown`, `mousedown`, `touchstart`, `touchmove`, `mousemove`, `click`）；
   - 在播放器视窗的所有点击与移动事件委托中，将 `.jc-code-preview-popover` 明确纳入排除白名单；
   - 卡片点击跳转优先执行并调用 `e.stopImmediatePropagation()` 终结事件传播；
3. **Shadow DOM 内部彻底戒除 `!important`**：
   - 使用普通属性 `visibility: hidden; pointer-events: none;` 替代 `!important` 堆叠，轻松将配额压降至安全线内。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN: 声明 `width: 100%` 结合横向 `padding` 时漏写 `box-sizing: border-box` -> USE: 所有带内边距的全宽容器必须严格标配 `box-sizing: border-box; max-width: 100%;`。
- FORBIDDEN: 纵向滚动容器不声明横向手势约束 -> USE: 所有纵向滚动列表与卡片必须显式声明 `touch-action: pan-y; overflow-x: hidden; overscroll-behavior-x: none;`。
- FORBIDDEN: 浮层或弹窗组件允许底层指针事件冒泡至视频区或控制层委托监听 -> USE: 在浮层根容器上统一拦截 `e.stopPropagation()`，保持交互自包含。
- FORBIDDEN: 在 Shadow DOM 内部盲目添加 `!important` 争夺特异度 -> USE: 依靠正确的 DOM 层次与类选择器层叠管理，将 `!important` 严格保留在全局最高优先级状态类中。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- RULE: 遵循全宽容器盒模型强制闭合约束：凡在组件样式中声明 `width: 100%` 并带有 `padding` 或 `border` 时，必须强制声明 `box-sizing: border-box; max-width: 100%;`，严禁依赖默认 `content-box` 造成视口物理撑爆溢出。(FORBIDDEN: `width: 100%; padding: 16px;` -> USE: `width: 100%; padding: 16px; box-sizing: border-box; max-width: 100%;`)
- RULE: 遵循纵向滚动容器手势硬约束：所有垂直滚动区域（如评论列表、骨架屏、状态盒）必须显式声明 `touch-action: pan-y; overflow-x: hidden; overscroll-behavior-x: none;`，严禁产生横向滚动通道与橡皮筋位移。(FORBIDDEN: `overflow-y: auto;` (漏设横向) -> USE: `overflow-y: auto; overflow-x: hidden; touch-action: pan-y;`)
- RULE: 遵循浮层组件交互硬隔离：所有绝对/固定定位的浮层组件（如预览浮窗、气泡提示）必须在根节点上彻底阻断所有指针事件冒泡（`pointerdown`, `touchstart`, `click`），且外部视频/控制监听必须将其加入排除白名单，严禁点击被底层机制消费。(FORBIDDEN: 浮层事件冒泡至播放器底层 -> USE: `pop.addEventListener('pointerdown', e => e.stopPropagation())`)
