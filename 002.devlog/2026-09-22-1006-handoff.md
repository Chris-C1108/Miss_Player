## 📌 本次核心成果拓扑

本次会话全面完成了 **Phase 6: 官方平台生态联动与版本生命周期管理**，正式将 SleazyFork / GreasyFork 官方提供的只读 JSON API 深度融合入 Miss Player 项目：

### 1. 核心网络与服务层 (`src/services/SleazyForkService.js`)
- **官方脚本绑定**：脚本 ID 锁定为官方主条目 `453300`；
- **只读零泄露合规**：纯本地 GET 请求拉取公开 JSON 元数据，杜绝附带任何用户行为、历史记录或设备指纹回传，严格遵守平台最高合规红线；
- **智能节流与缓存**：内置 `12 小时本地 TTL 缓存机制` (`mp_sleazyfork_meta_cache` 与 `mp_sleazyfork_last_check`)，用户页面刷新不滥用外部平台接口；手动点击检查时支持跳过缓存强刷；
- **鲁棒的 Semver 算法**：实现容错的语义化版本比对（过滤 'v' 前缀与预发布标记），精确识别是否有更新可用；
- **主备容灾切换**：优先请求 `sleazyfork.org`，网络或屏蔽时自动无缝故障转移至 `greasyfork.org`。

### 2. UI/UX 与微前端交互层 (`SettingsManager.js` & `_player.css`)
- **Apple 毛玻璃「关于与更新」卡片**：
  - 顶部呈现应用标题、当前版本徽章与 SleazyFork 主页直达；
  - 动态展示真实社区活跃度微胶囊（总安装量、评分、更新时间等）；
- **平滑一键更新与版本日志**：
  - 检测到新版时，版本徽章变为高亮脉冲 `NEW vX.X.X`，弹出醒目升级提示；
  - 提供「立即更新」按钮（在新标签页直接调起 Userscript 管理器安装确认）与「版本日志」直达；
- **非侵入式后台静默检查与红点**：
  - 启动后闲时自动静默检查；
  - 发现新版时，仅在播放器设置齿轮（`tm-settings-button`）右上角点亮极简呼吸红点徽章，不弹窗打扰观影；
- **国际化完备覆盖**：在 `src/constants/i18n.js` 中补全 `en`, `zh-CN`, `zh-TW`, `ja`, `vi` 全部 5 种语言的 15 项词条。

### 3. 工程化与 CI 自动化保障 (`scripts/ci-test.js` & `tests/sleazyfork.test.mjs`)
- 编写专门的单元测试 `tests/sleazyfork.test.mjs`，覆盖 Semver 比对、i18n 完备性及真实 API 接口握手；
- 嵌入 `npm run ci:check` 自动化流水线，成为发版前的必过合规门禁；
- 在 `vite.config.mjs` 与 `webpack.config.js` 的 `@connect` 白名单中显式声明 `sleazyfork.org` 与 `greasyfork.org`。
