# Session Lessons & Anti-Patterns: iOS 视口键盘双重位移、ShadowDOM 捕获重定向陷阱与沙箱生命周期治理

- Date & Time: 2026-11-03 18:12:33
- Focus Module: iOS Viewport, Shadow DOM Events, Userscript Extension Ecosystem

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
1. **iOS Safari 虚拟键盘弹起双重位移 (Double-Shift Offset)**：
   - 现象：输入框聚焦唤起软键盘时，发评栏瞬间冲出视口飞向屏幕上方（SubmitBarGap: -363px），或者输入框被下压遮挡在键盘背后（Clearance: -355px），页面剧烈抖动。
   - 触发条件：宿主长页面（scrollHeight 达 4000px+）处于激活状态时，在移动端 WebKit 唤起虚拟键盘。
2. **Shadow DOM 跨边界事件捕获阶段重定向导致弹窗自杀式销毁**：
   - 现象：用户点击高光备注修改弹窗（`.tm-inline-remark-popover`）中的输入框时，弹窗瞬间凭空消失，根本无法输入文字。
   - 触发条件：弹窗挂载在 Shadow DOM 内部，而外部在 `document` 上以**捕获阶段 (`useCapture: true`)** 监听 `handleOutsideClick`，并通过 `popover.contains(e.target)` 判断是否点击外部。
3. **iOS WebKit 异步聚焦打字拦截 (Blocked Asynchronous Focus)**：
   - 现象：用户点击草稿编辑按键，输入框已弹出，但光标未进入，虚拟键盘未唤起，必须手动二次点按输入框。
   - 触发条件：在 `requestAnimationFrame` 或 `setTimeout` 等微任务回调中调用 `input.focus()`。
4. **浮动按钮在播放器激活后死灰复燃 (Resurrected Floating Button)**：
   - 现象：进入播放器后，粉色浮动圆钮不但没有隐藏，反而以 `z-index: 2147483640` 强行悬浮覆盖在全屏播放器控制面板正上方，阻挡打点与进度操作。
   - 触发条件：页面发生 DOM 变动或转屏时，`FloatingButton.js` 的 `MutationObserver` 与 `resize` 监听器检测到视频存在，盲目将 `button.style.display` 设回 `flex`。
5. **重构未声明变量引发的崩溃与 DOM 漏挂载**：
   - 现象：点击浮动按钮后，按钮隐藏、视频变成占位符，但播放器界面完全不显示，控制台报错 `ReferenceError: selectAllBtn is not defined`。
   - 触发条件：重构组件模板时遗留了旧模态框的事件绑定逻辑。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
1. **WebKit 滚动协助与 JS 视口补正的叠加冲突**：
   - 移动端 WebKit 在宿主存在 `scrollHeight > clientHeight` 时，聚焦输入框会强行执行原生的 `scrollIntoView`，将 `window.scrollY` 滚起 363px；
   - 同时，JS 的 `visualViewport` 监听器计算出 `keyboardHeight = 363px` 并设置了 `bottom = 363px`；两者叠加造成 726px 的超额偏移（Double Shift）。
2. **W3C Shadow DOM 规范中的事件重定向 (Event Retargeting)**：
   - 当 Shadow DOM 内部产生的事件向外冒泡跨越 Shadow 边界到达宿主 `document` 时，浏览器出于封装安全，会将 `e.target` 强制替换为宿主自定义元素（`<miss-player-root>`）；
   - 在捕获阶段，宿主捕获到点击事件，此时 `e.target` 为 `<miss-player-root>`，`popover.contains(<miss-player-root>)` 永远返回 `false`，导致代码误判为“点击了弹窗外部”，立即执行销毁回调。
3. **WebKit 安全手势信任链约束 (User Gesture Activation Gate)**：
   - iOS Safari 为防止恶意网页滥调键盘弹窗，严格要求 `input.focus()` 必须处于用户直接触摸事件的**同步调用栈**中；脱离调用栈（放入 rAF）会被直接静默丢弃。
4. **浮动按钮生命周期缺乏全屏激活状态感知**：
   - 浮动按钮的轮询与变动监听只检查了“页面是否存在视频元素”，未感知“Miss Player 自身是否已经激活”，播放器内部劫持的视频被误当成需要挂载浮动按钮的目标。

## 3. PROVEN SOLUTION (验证有效的解决方案)
1. **ComposedPath 跨边界事件穿透检测**：
   ```javascript
   const handleOutsideClick = (e) => {
       const path = e.composedPath ? e.composedPath() : [];
       if (path.length > 0) {
           if (path.includes(popover)) return; // 真实命中弹窗内部，放行
       } else if (popover.contains(e.target)) {
           return;
       }
       close();
   };
   // 必须在冒泡阶段监听，且避免捕获截杀
   document.addEventListener('click', handleOutsideClick, false);
   document.addEventListener('touchend', handleOutsideClick, false);
   ```
2. **手势同步立即聚焦与文字选中**：
   ```javascript
   parentContainer.appendChild(popover);
   // 同步直接聚焦，100% 唤起 iOS 键盘
   try { input.focus({ preventScroll: true }); } catch (_) { input.focus(); }
   input.select();
   requestAnimationFrame(() => { popover.classList.add('visible'); });
   ```
3. **浮动按钮激活期全生命周期压制**：
   ```javascript
   isPlayerActive() {
       return Boolean(
           (document.body && document.body.classList.contains('tm-player-active')) ||
           (document.documentElement && document.documentElement.classList.contains('tm-player-active')) ||
           document.querySelector('miss-player-root')
       );
   }
   // 在 handleDomMutations、handleResize、startVideoElementCheck 中首行熔断：
   if (this.isPlayerActive()) {
       if (this.button) this.button.style.display = 'none';
       return;
   }
   ```
   并在 `_host.css` 中声明：
   ```css
   html.tm-player-active .tm-floating-button,
   body.tm-player-active .tm-floating-button {
     display: none !important;
   }
   ```
4. **基于 sessionStorage 的番号隔离评论草稿持久化**：
   ```javascript
   saveCommentDraft() {
       const key = 'mp_comment_draft_' + this.getVideoCode();
       const val = this.commentInput?.value;
       if (val?.trim()) sessionStorage.setItem(key, val);
       else sessionStorage.removeItem(key);
   }
   ```
5. **油猴管理器协议一键安装生态适配**：
   - Stay (iOS Safari): `stay://x-callback-url/open-install?url=${encodeURIComponent(userJsUrl)}`
   - Tampermonkey: `https://www.tampermonkey.net/script_installation.php#url=${encodeURIComponent(userJsUrl)}`
   - ScriptCat: `https://docs.scriptcat.org/docs/script_installation/#url=${encodeURIComponent(userJsUrl)}`

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN: 在 `document` 上使用 `popover.contains(e.target)` 来判断 Shadow DOM 内部元素的点击外部 -> USE: 必须使用 `e.composedPath().includes(popover)`，防止事件跨边界重定向导致误杀。
- FORBIDDEN: 在 `document` 捕获阶段 (`useCapture: true`) 监听外部点击关闭弹窗 -> USE: 统一使用冒泡阶段 (`useCapture: false`) 并在弹窗根容器上执行 `stopPropagation()`。
- FORBIDDEN: 将 `input.focus()` 放入 `requestAnimationFrame` 或 `setTimeout` 中执行 -> USE: 必须在用户点击手势的同一同步调用栈顶端执行 `input.focus({ preventScroll: true })`。
- FORBIDDEN: 浮动按钮的轮询与 DOM 观察器仅校验 `findVideoElement()` -> USE: 必须先行校验 `isPlayerActive()`，在播放器运行期间严禁以任何理由重新展示浮动按钮。
- FORBIDDEN: 重构组件时仅替换 HTML 模板而遗留旧 DOM 的事件监听变量引用 -> USE: 必须同步审查变量声明并执行全链路静态语法检查（AST / compliance-lint / sandbox）。
- FORBIDDEN: 移动端发评组件常驻大面积暗黑模糊遮罩阻塞用户视线 -> USE: 移除模糊背景层，让用户边看视频画面/评论列表边输入，并支持轻点胶囊一键 Seek 对应片段。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
- 提炼原子规则：
  `RULE: Shadow DOM 内部弹窗的 OutsideClick 判定必须遍历 e.composedPath()，严禁使用捕获阶段与 popover.contains(e.target)；iOS 文本聚焦必须在用户点击直接同步调用栈执行，严禁放入 rAF 或异步回调。`
