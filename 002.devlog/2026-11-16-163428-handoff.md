## 1. 本次解决的核心问题

针对用户反馈“新版设置菜单（Settings v2）无法上下滚动、存在幻觉/错误选项且缺失旧版设置项”的问题，按顶级领域专家审计结论完成全链路修复与 Playwright 实机验证：

1. **彻底修复面板无法滚动与交互白名单遗漏**：
   - `src/player/managers/EventManager.js`：在 `scrollableSelector` 中补充 `.mp-s2-panel, .mp-s2-scroll`，防止全局 `touchmove` 监听器拦截移动端滑动；
   - `src/player/managers/settings_v2/SettingsV2Manager.js`：将 `_bindHeaderDismissGesture` 的 `touchstart` 触发区严格收拢到 `.mp-s2-header`，禁止在 `.mp-s2-scroll` 顶部的正常下拉手势被劫持为面板关闭；
   - `src/player/ui/UIManager.js`：在 `nonControlOverlaySelector` 及控制栏 `mouseenter`/`mouseleave` 悬浮防隐藏选择器中补齐 `.mp-s2-panel` 与 `.tm-settings-v2-button`；
   - `src/player/ui/styles/02_components/_settings_v2.css`：将 `.mp-s2-panel` 的 `max-height` 约束为 `min(calc(100% - ...), ...)`（涵盖桌面、内联非全屏播放器、竖屏 Bottom Sheet 及横屏矮视口 `@media (max-height: 500px)`），确保任何容器高度下由 `.mp-s2-scroll` 独立滚动承载而非被外层溢出裁切；同步为 `.mp-s2-stepper-box` 与 `.mp-s2-unit` 增加 `flex-shrink: 0` / `white-space: nowrap`，消除 `分钟` 换行。

2. **清除幻觉配置项并 1:1 对齐真实 PlayerState / Manager 契约**：
   - **播放控制 (`src/player/managers/settings_v2/sections/S2PlaybackSection.js`)**：
     - 清除不存在的 `remoteControlMode`（遥控器模式）、`showModeControlRow`（底部模式切换）、`betaColorPlayMode`（点选胶囊模式）及死方法 `updateRemoteModeUI` / `updateBetaPlayModeUI`；
     - 修正错误键名 `customSeekSteps` → `customUserSeekSteps`；
     - 补全旧版真实播放配置：`pauseOnBlur`（离开暂停）、`defaultMuted`（默认静音）与条件展开子项 `muteResetMinutes`（静音租约 1–120 分钟）。
   - **影片评论 (`src/player/managers/settings_v2/sections/S2CommentsSection.js`)**：
     - 清除不存在的 `commentSortOrder` 与 `updateSortButtonsUI` / `renderComments`；
     - 修正 `enabledCommentSources` 数据结构由数组改为旧版一致的对象映射 `{ jable, javdb, javlibrary }` 并调用 `commentPanel.updateCommentSources(nextMap)`；
     - 补全旧版真实评论配置：`showCommentsSection`（显示评论，联动 `sidebarHidden` 与 `commentPanel.updateCommentsVisibility`）和 `debugFilterHasNumbers`（只看时间，调用 `commentPanel.updateFilterHasNumbers`）。
   - **连接与同步 (`src/player/managers/settings_v2/sections/S2ConnectionsSection.js`)**：
     - 修正 WebDAV 配置读写字段 `config.username` / `config.password` → `config.user` / `config.pass`，与 `SyncManager` / `WebDavClient` 完全对齐。
   - **高级与关于 (`src/player/managers/settings_v2/sections/S2AdvancedSection.js`)**：

   - **国际化字典 (`src/constants/i18n.js`)**：清理已移除幻觉项对应的 `s2RemoteMode` 等 11 个死键。
