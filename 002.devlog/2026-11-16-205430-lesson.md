# Lessons Learned — 2026-11-16 20:54:30 (v5.7.118-beta.053)

## 1. 邻近高亮状态机与防闪烁治理
- **FORBIDDEN**: 仅用 `Math.abs(curTime - t) <= 5` + 数组首项命中 (`if (!currentNearTab) currentNearTab = ...`) + 在 `renderTabs()` 重建 DOM 后清空 `.near`，且仅依赖 `timeupdate` 更新高亮。
- **USE**:
  1. **纯函数五态机 + 非对称前瞻/滞回**：采用 `editing > looping > inside > near > idle` 严格互斥分层；单点前瞻采用非对称 `-6s / +4s`（人脑识别预览需要更长前瞻，离开保留缓冲），并在退出边施加 `+1.5s` 滞回（Hysteresis）防止临界倍速/抖动时闪烁。
  2. **多胶囊距离与跨度裁决**：当多个胶囊同时接近时，优先按状态等级、距播放头真实距离及更紧凑区间跨度裁决唯一 `primaryTabId`，并对主焦点切换施加 `1.2s` 滞回。
  3. **多事件全周期驱动**：在 `seeked`、`durationchange`、`loadedmetadata` 与 `checkAndExitLoopIfOutside` 入口均调用 `syncProximityState`，确保暂停拖动进度条或评论跳转时瞬时高亮；仅在 `primaryTabId` 变化时触发居中滚动。

## 2. 胶囊内部进度条与循环图标可读性
- **FORBIDDEN**: 在 JS 中通过 `pill.style.background = linear-gradient(...)` 内联覆写静态渐变背景，或用居中绝对定位 `.tm-tab-loop-overlay` 把 SVG 叠在时间数字正上方遮挡可读性。
- **USE**:
  - 使用独立底层节点 `.tm-tab-progress-fill` 配合 `--tab-progress` (`0..1`) 和 `transform: scaleX(var(--tab-progress, 0))`，实现零重排 GPU 合成器推进；
  - 将循环图标改造成内联 Flex 徽章 `.tm-tab-loop-badge`（前置紧邻时间文字），确保文字在 `looping` 态下 100% 清晰可见。
