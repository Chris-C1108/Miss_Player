- [x] **修复「中途退出播放器后，再次点击浮动按钮进入播放器又跳回首个高光」问题** (`src/player/core/PlayerCore.js`, `src/player/CustomVideoPlayer.js`, `src/player/managers/ProgressManager.js`, `tests/first-highlight-seek.test.mjs`)：
  - 新增 `getTheaterSessionKey()` 与 `shouldTriggerInitialHighlight()`，并在 `PlayerCore` 上实现 `hasEnteredTheaterBefore()` / `markTheaterEntered()`：同步通过视频节点 `dataset.mpTheaterEnteredKey` 与 `FloatingButton._enteredTheaterKeys` 记住当前视频是否已进入过影院模式（SPA 切换新番号仍允许首次触发，宿主重建同片 `<video>` 仍识别为重入）。

- [x] **实现「自动优先字幕：简体中文与繁体中文互为备选及自动繁简转换」** (`src/player/subtitles/SubtitleChineseMaps.js`, `src/player/subtitles/SubtitleChineseConverter.js`, `src/player/subtitles/SubtitleManager.js`, `src/constants/i18n.js`, `tests/subtitle-render.test.mjs`)：
  - 新增零依赖简繁转换模块（2550 简转繁 / 3048 繁转简码点映射表 + 字幕高频词组消歧表），提供 `detectChineseScript()`、`convertChineseText()` 与 `convertSubtitleContent()`，支持 SRT / ASS(SSA) / WebVTT 保真转换（跳过时间戳、样式区块、`{\pos(...)}` 及 HTML 标签）。
  - 在 `SubtitleManager.js` 实现 `getChineseFallbackLang()`、两级 `rankPreferredCandidates()`（Tier 0 精确语种 > Tier 1 简繁互备，按评分降序）与 `applyPreferredChineseConversion()`：设置简中仅有繁中时繁转简（`简中(繁转)`），设置繁中仅有简中时简转繁（`繁中(简转)`），通用中文标实为繁体时仅校准标签避免二次污染，转换结果同步写入 IndexedDB 与 WebDAV。
