# 架构教训与避坑指南 (Lesson Learned - 2026-11-13 13:22:00)

## 🚨 成对反模式禁令规范 (FORBIDDEN vs USE)

### 1. 移动端滑动切源手势实现规范 (Follow-Finger vs Raw Touchend Trigger)
- **FORBIDDEN: 仅在 touchend 时计算 deltaX 进行粗暴翻页，拖拽过程中 DOM 毫无位移反馈**
  - **陷阱后果**：用户手指在屏幕上水平拖动时，画面静止死板，用户无法感知手势是否被系统捕捉，往往误以为滑动失效或发生卡死；
- **USE: 必须采用轴向锁定的实时跟手物理位移 (Live translate3d with Damping & Snap)**
  - **正规做法**：在 touchmove 阶段通过 `Math.abs(diffX) > Math.abs(diffY) * 1.2` 锁定主轴并阻止纵向滚动；拖拽过程中关闭 CSS transition，通过 `translate3d(diffX, 0, 0)` 1:1 跟手移动；在端点施加 `0.28` 弹性阻尼；并在 touchend 时通过 `cubic-bezier(0.16, 1, 0.3, 1)` 曲线执行翻页或弹性回弹。

### 2. 多源 TabBar 与系统设置状态同步规范 (Dynamic Setting Alignment)
- **FORBIDDEN: 在 UI 模板中硬编码写死全量站点 Tab 列表，或仅通过 CSS display: none 隐藏下层 Section 而不更新顶部 Tab**
  - **陷阱后果**：当用户在设置中关闭了某源（例如 JAVLib），顶部 Tab 依然常驻该站点按钮，点击后显示空白；滑动切换时仍会切入被禁用的空源；
- **USE: 建立统一的启用的源计算漏斗 (getEnabledCommentSources)，动态装配 TabBar 与滑动源**
  - **正规做法**：统一收敛为 `getEnabledCommentSources()`；TabBar 仅动态生成已开启的站点 Tab；滑动手势仅在已开启的站点子集中索引翻页；若当前激活源被外部设置停用，自动平滑 fallback 到首个可用源。

### 3. 操作按钮的去 Emoji 化与微胶囊设计 (De-Emoji Micro-Capsule)
- **FORBIDDEN: 在高密度评论条目操作按钮中使用花哨的 emoji 图标（如 📌, 🐛, ⏱）**
  - **陷阱后果**：各移动操作系统（iOS、Android、不同版本 WebKit）的 emoji 渲染尺寸、基线对齐和彩度差异极大，在暗黑沉浸界面中极其扎眼，呈现廉价工控感与 AI-Slop 质感；
- **USE: 统一采用纯文字、高质感半透明微胶囊 (Apple Micro-Typography Pill)**
  - **正规做法**：去除 emoji，采用高度 22px、字号 11px、字重 500 的正圆角纯文本微胶囊（如 `转存`、`上报`、`高能现场`）；依靠细腻的半透明底色（`rgba(255, 255, 255, 0.06)`）与轻柔边框传达层级，并在 active 态施加 `scale(0.95)` 触控反馈。
