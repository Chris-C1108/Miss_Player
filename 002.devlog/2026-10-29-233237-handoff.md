## 1. COMPLETED OBJECTIVES (已完成工作)
- [x] **根治番号预览卡片首击误唤醒控制栏 BUG**：
  - 在 `CommentPanel.js` 中为 `_codePreviewPopover` 注入全生命周期事件硬隔离（`pointerdown`, `mousedown`, `touchstart`, `touchmove`, `mousemove`, `click` 均阻止冒泡）；
  - 在 `UIManager.js` 的 `videoWrapper` 点击以及容器移动监听中将 `.jc-code-preview-popover` 明确加入排除白名单；
  - 调整卡片内跳转事件为立即优先执行（`e.stopImmediatePropagation()`），点击第一次即直接平滑跳转至目标页面，不再被误判定为视频点击。
- [x] **根治评论区 Loading 态盒模型物理溢出与横向滑动晃动**：
  - 结合移动端调试截图定位出 `div.tm-comment-loader-graphic` 尺寸为 `376 x 38` 撑爆父容器（344px）的根因：原 CSS 声明了 `width: 100%` 与 `padding: 16px` 却漏写了 `box-sizing: border-box`，在浏览器默认 `content-box` 下导致实际物理总宽度为 `100% + 32px`，直接撑爆视口；
  - 补齐 `box-sizing: border-box` 与 `max-width: 100%`，并在父级 `.tm-comment-section` 与 `.tm-comment-section-body` 上全面注入 `overflow-x: hidden`、`touch-action: pan-y` 与 `overscroll-behavior-x: none`；
  - 补齐骨架屏 `.mp-comments-loading` 的 `pointer-events: auto` 与纵向滚动属性，彻底切断向底层宿主网页的触控击穿，手指斜向滑拉绝不再产生任何左右位移。
- [x] **严格守卫 `!important` 数量安全限额**：
  - 门禁脚本成功拦截了多余的 `!important` 新增；将 Shadow DOM 内部普通类选择器的冗余 `!important` 剔除，数量安全回落至 98 处（上限 101 处）。
