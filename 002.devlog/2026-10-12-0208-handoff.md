## 🎯 本阶段核心成果与架构拓扑

1. **控制面板与 Gutter 边距体系纯净化**：
   - 取消 `.tm-control-buttons` 自带的 padding，内边距完全由外层 iOS 键盘底板 `.tm-control-panel` 统一下发，严格自适应安全区；
   - 取消 `.tm-single-hand-gutter` 上散落的所有 margin 与 padding，两者间距完全通过底板的 flex `gap: 8px` 进行弹性管控；
2. **手势驱动的单手模式与尺寸边界守卫**：
   - 彻底废除全宽模式下悬浮于右下角的 44px 独立角标按键方案，全宽状态下界面纯净无冗余控件；
   - 单手模式触发方式升级为在 `.tm-seek-control-row` 区域水平手势滑动：
     - 向左滑动（Swipe Left）➔ 开启左手单手模式（面板靠左，Gutter 靠右并吃满剩余空间）；
     - 向右滑动（Swipe Right）➔ 开启右手单手模式（面板靠右，Gutter 靠左并吃满剩余空间）；
     - 修复 DOM 挂载先 buttons 后 gutter 导致的 flex 轴向颠倒问题（左手用 `row`，右手用 `row-reverse`）；
   - 在 iPhone 标准版（390px）与 Pro（393px / 402px）及大屏设备上，控制面板最大宽度严格限制在黄金 320px，保证 6 个时间控制按键永远排成 2 行（每行 3 个）；
   - 限制更窄的屏幕（`< 380px`，如 iPhone SE、mini 及老旧紧凑屏）不支持开启单手模式，手势滑动进行友好拦截并弹出多语言 Toast 提示；
3. **播放控制行 (`tm-playback-control-row`) 双层叠加与零内嵌样式重构**：
   - 彻底清除所有 HTML 内联样式（Zero Inline Styles），静态规则全量收敛至 `_controls.css` 与 `_player.css`；
   - 搭建 2 层叠加架构：
     - 底层：100% 全宽的视频状态切换器 Switcher (`mp-switcher-capsule`)；
     - 上层：[左侧音量 & 右侧倍速] 悬浮控制层，中间容器放行穿透；
   - 左右滑动 Switcher 时，上层 [左 & 右] 组件以 0.28s 苹果动效向两侧滑出并淡出隐藏；松手吸附后优雅滑回恢复；
   - 拖拽与吸附步进严格限制为单步进（`step = ±1`，物理拖动限制在 `currentIndex ± 1`），彻底杜绝跨档位跳至最后一个；
   - Switcher 内部操作按钮 SVG 图标统一为纯白高亮；
4. **控制底板与 Switcher 光感与描边纯净化 (Box-Shadow 方案)**：
   - 移除 `.tm-control-panel` 的单色实体背景，仅保留沉浸式 `background-image: linear-gradient(#1a1a20e0, #000000)`；
   - 取消 `border-top` 与全部 `border-*` 属性，全面改用纯净内阴影 `box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.18)`，完美解决顶部 1px 边框在 20px 圆角处被 WebKit 裁切及与阴影叠加过重的瑕疵；
   - `.mp-switcher-indicator` 同步取消 border，采用 `box-shadow: inset 0 1px 0 0 #ffffff38` 光感描边与半透明底色。
