# Session Lessons & Anti-Patterns: 油猴安全边界、Safari 兼容性裁剪、CSS 四层治理与资产瘦身

- Date & Time: 2026-11-13 00:51:42
- Focus Module: `CommentDataPipeline` / `CommentCardRenderer` / `src/index.js` / `src/player/ui/styles/` / `scripts/audit-css.js`

## 1. PROBLEMS ENCOUNTERED (遇到的核心问题与故障)
- **通用 Web 建议照搬到油猴与 Safari 时失真**：直接套用 Chrome/Firefox 向最佳实践会引入 Safari 不支持的 API（如 `Element.setHTML()`、`interpolate-size`、`<dialog closedby="any">`、`Element.moveBefore()`），同时忽略油猴环境下 `GM_*` 沙箱隔离与跨域 iframe 动态域名镜像的真实约束。
- **CSS 静态审计误报与死循环风险**：旧版 `scripts/audit-css.js` 仅扫描根目录 CSS（遗漏 `00_tokens/`、`01_core/`、`02_components/` 子目录），且未识别 JS 动态拼串类名（如 `` `tm-status-badge-${site.status}` ``）及 `_host.css` 宿主压制白名单，若盲删会破坏运行期 UI。
- **CSS 物理拆分后测试与规则错位**：初次使用行号正则拆分 `_player.css` 时曾误把 `@media (min-width: 1024px)` 内部规则归类拆碎、并导致 7 个直接读取旧 CSS 路径的单元测试报错；同时 `tests/xss-sanitization.test.mjs` 初版断言 `includes('onclick=') === false` 误判了已被 `&quot;` 安全转义的 `data-id` 属性文本。
- **Vite CSS 拆分中的大图标冗余与 JS 体积真相**：`PEACH_LOGO_IMAGE` 原图采用 160×160 RGBA PNG（50.9 KiB Base64）却仅在 `20×20` 按钮渲染；而即便开启 `cssMinify: true` 并将 CSS 压缩至 `150.88 KiB`，在 GreasyFork 严禁 JS 混淆压缩（`minify: false`）约束下，纯 JS + Header 本身已占 `1036.06 KiB`。

## 2. ROOT CAUSE ANALYSIS (根本原因剖析)
- **油猴 XSS 真正威胁面在宿主 Cookie 与 DOM 钓鱼**：第三方评论进入宿主文档树虽无法直接读取沙箱 `GM_getValue`，但 `esc()` 未转义双/单引号与 `[url]/[color]` 未做协议/属性校验，可在已自动登录的宿主域上执行脚本并伪造 Shadow DOM 内配对钓鱼框。
- **Safari WebKit 中文输入法组合确认键陷阱**：Safari 下拼音/日文候选词确认回车时 `event.isComposing` 可能提前变为 `false`，但 `event.keyCode` 仍为 `229`（WebKit bug 165004），仅检查 `!e.isComposing` 依然会在确认候选词瞬间误触发表或提交。
- **PostCSS AST vs 文本正则拆解差异**：CSS 文件内 `@media` 与复合选择器嵌套跨行时，基于行号/文本启发式的脚本极易截断大括号或误判作用域归属，必须以 `postcss.parse` AST 顶层节点为单位路由。
- **单行 100% 转义断言与属性内字面量的区别**：`escapeHtml('c1" onclick="alert(1)')` 的产物 `c1&quot; onclick=&quot;alert(1)` 仍包含 `onclick=` 子串，但其处于合法双引号属性值内，不构成属性逃逸。

## 3. PROVEN SOLUTION (验证有效的解决方案)
- **零依赖全浏览器安全的 XSS 防线**：在 `CommentDataPipeline.js` 使用 5 字符映射 `esc()`（`& " ' < >`）+ `sanitizeCommentUrl()`（`new URL` 仅放行 `http:`/`https:` 且附 `rel="noopener noreferrer"`）+ `sanitizeCommentColor()`；为跨帧消息 `MP_IFRAME_*` 校验 `event.source` 归属。
- **全库统一 IME 守卫**：在 `src/utils/dom.js` 抽出 `isImeConfirmEnter(e)`（`e.key === 'Enter' && !e.isComposing && e.keyCode !== 229`），覆盖全部 7 处输入框/模态框键盘提交。
- **Ast 级 CSS 四层拆解与工具升级**：利用 `postcss.parse` 节点路由无损拆解为 4 层 20 模块（单文件均 `≤ 789` 行），升级 `scripts/audit-css.js` 支持递归目录、模板字符串提取与 `_host.css` 豁免，实测 Grade-1 死选择器清零、`!important` 降至 `45` 处（门禁棘轮锁定 `≤ 50`）。
- **高分辨率位图降采样为 3.2× WebP**：将 `160×160` PNG 降采样为 `64×64` WebP（`-q 85 -alpha_q 90`，1,550 B / 2,091 Base64 字符，`-48.8 KiB`），在 20px Retina 按钮上无损清晰且全端兼容。
- **非目标子帧早期短路与大类职责拆分**：在 `src/index.js` 前置 `_shouldInitMediaHooks()` 过滤非 HTTP(S) 与非播放器广告/统计 iframe；将 `CommentPanel.js`（预览/上报/卡片渲染）与 `UIManager.js`（软键盘适配/Top-Layer 挂载）拆分为独立内聚模块。

## 4. PITFALLS & ANTI-PATTERNS (避坑指南与反模式禁令)
- FORBIDDEN: 在需要兼容 Safari 14+ / iOS Stay 的油猴脚本中直接引入 `Element.setHTML()`、`interpolate-size`、`<dialog closedby="any">`、`moveBefore()` 或无兜底的 `scheduler.yield()` -> USE: 采用纯 JS 字符转义与 URL 协议白名单、`CSSStyleSheet` + `<style>` 特性检测降级、`color-scheme: dark`、`prefers-reduced-motion` 与 `content-visibility: auto` 等 Safari 兼容渐进增强特性。
- FORBIDDEN: 仅依赖 `e.key === 'Enter' && !e.isComposing` 判定回车提交 -> USE: 统一调用 `isImeConfirmEnter(e)` 同时排除 `e.isComposing` 与 `e.keyCode === 229`（规避 Safari WebKit bug 165004）。
- FORBIDDEN: 在多文件 CSS 拆解中按行号或正则截取片段，或盲从静态审计 0 引用名单批量删 CSS -> USE: 基于 `postcss.parse` 顶层 AST 节点分类迁移，并结合 JS 动态模板前缀与宿主类名人工二次核验后再删。
- FORBIDDEN: 在脚本内嵌大尺寸渲染冗余的 PNG Base64 图标（如 20px 按钮内嵌 160×160 50KB PNG）-> USE: 按目标尺寸 2×–3.2× 降采样为 WebP Data URI 或矢量化 SVG。
- FORBIDDEN: 未验证子帧协议与宿主/播放器特征就在 `@run-at document-start` 对所有第三方广告/统计 iframe 全量注入 `AdBlocker` 与 `MediaSniffer` -> USE: 在入口最顶端执行轻量上下文白名单短路（`_shouldInitMediaHooks()`）。

## 5. SCALING TO AGENTS.MD (全局规则提炼)
